# Ambient Lab v0.1.0

현재까지의 작업을 보존하는 첫 Git 버전이다. 모든 실험의 완성도나 모든 엔진의 연결 완료를 뜻하지 않는다.

## 포함 범위

- Nx 기반 작업 실행, pnpm 기반 JavaScript/TypeScript, uv 기반 Python 워크스페이스.
- Strudel 음악·패턴, PCM 분석, WAV 출력과 영상 제작 도구.
- 사운드–비주얼 작업대, 엔진 비교 화면과 실험별 제작 화면.
- Three.js 기반 Mandelbulb 장면, 깊이·음악 특징에 반응하는 색채, 원본 드럼 샘플 킷, 레시피 영상 출력.
- 윤슬·dp-sts 및 저장된 후속 실험의 소스, 악보·레시피, 컨셉·리서치·검수 문서.
- TouchDesigner/cables 연계 코드와 실행 상태를 구분하는 기록.

## 검증과 한계

- 버전 준비 시 `pnpm nx run-many -t build,typecheck,lint,test`: 13개 작업 성공, 이 중 5개 캐시 사용.
- 레시피 기반 dp-sts 출력은 89.43초, 1920×1080, 30fps, 2683프레임이다. 상세 증거와 독립 검수 범위는 `docs/agent-system/recipe-film-state.md`와 `recipe-film-critique.md`를 따른다.
- 실제 청취 평가와 교정본에 대한 Astra의 최종 재확인은 완료된 것으로 주장하지 않는다.
- 다른 실험의 검증 범위는 각 실험 문서를 따른다. 작업대에서 선택 가능한 도구가 모두 실제 연결되었다는 의미는 아니다.

## 보관 정책

소스·설정·문서·필수 에셋과 잠금 파일을 Git으로 보관한다. 기존 `.gitignore` 정책에 따라 `runs/`의 렌더 영상·분석 출력, 로컬 전용 에셋, 의존성, 빌드·캐시는 커밋하지 않는다. 따라서 저장소 복제만으로 기존 렌더 영상 파일이 내려오지는 않는다.

최종 레시피 영상의 로컬 경로: `runs/recipe-film-v02/dp-sts-chromatic-mandelbulb-final.mp4`.
