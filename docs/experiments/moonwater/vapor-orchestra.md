# dp-sts · 전자 관현악과 프랙털 증기 공간

## 최신 장르 변경 · Downtempo Folktronica

사용자 후속 지시: “음악장르를 사이키델릭에서 Downtempo Folktronica 장르로 하자”. 이 지시가 현재 음악 방향이다. 아래 관현악 탐색은 이전 단계의 기록으로 보존한다.

72 BPM과 아베 마리아 주선율의 음정·길이 관계를 유지하되, 뜯는 현의 배음·감쇠와 나무 울림을 합성한 리드, 리드/목관형 선율, 핑거피킹 반주, 따뜻한 베이스, 성긴 브로큰 킥, 브러시와 셰이커를 중심에 둔다. 반주·타악 일부의 엇박은 45ms 늦춰 느슨한 흐름을 만든다. 현악 패드는 배경으로 줄이고 브라스는 제외한다. 실제 기타 연주나 어쿠스틱 샘플을 사용했다고 주장하지 않는다.

별도 Strudel 편성 `compositions/vapor-folktronica`에서 2,406개 이벤트를 질의해 새 음원을 합성한다. 새 음원의 대역과 RMS를 다시 측정해 실제 3D 카메라와 Hydra에 공급한다. 이전 관현악 시안의 음원·영상은 보존한다.

```sh
pnpm nx run media:vapor-score --folktronica
pnpm nx run media:vapor --audio --score=compositions/vapor-folktronica/score.json --out=runs/dp-sts-folktronica-base-v01
pnpm nx run media:vapor --out=runs/dp-sts-folktronica-base-v01
```

2026-11-02. 사용자는 기존 음악이 너무 느리고 낮으며 선율만 있다고 지적했다. 원곡의 흔적을 남긴 전자 관현악과, 거시·미시 입자 공간을 음악에 맞춰 이동하는 카메라를 요청했다. 입자는 기화하듯 흩어지고 뭉치며 흐려져야 한다.

## 새 음악

- 구현 선택: 72 BPM. 이전 17.86 BPM보다 선율 진행을 약 4배 빠르게 한다.
- 아베 마리아의 121음 순서와 상대 길이를 보존하고 이전보다 한 옥타브 높인다. 현재 주선율 기본 주파수는 약 131–440Hz다.
- 네 번의 주제 전개를 목관형 합성음과 전자 현악이 교대한다. 전자 현악 패드, 하프형 플럭, 브라스 팽창, 베이스, 부드러운 저음 타격과 공기 타악을 더한다.
- 반주는 선율 음을 고려한 새 화성 편곡이다. 바흐 반주 원전의 정확한 전사라고 주장하지 않는다.
- 각 전개 사이에는 지속화음을 두어 잔향과 다음 도입을 연결한다.
- **실제 Strudel 질의에서 나온 편성 이벤트가 Python 오프라인 합성의 입력이다.** 이전 Hydra 버전의 '원음 보존+패턴 대조'와 달리 새 음원을 합성한다. 관현악 샘플이나 실연 녹음은 쓰지 않는다.

## 새 공간

32,000개 점을 큰 군집과 네 단계의 작은 분기 오프셋으로 배치한다. 유한 단계의 자기유사 입자 구조이며, 엄밀한 무한 프랙털이나 물리 유체 시뮬레이션이라고 부르지 않는다.

카메라는 실제 3D 위치·시선과 원근 투영을 갖는다. 20·165·310·455초의 음악 주제 전개에 맞춘 145초 접근/후퇴 곡선에, 실제 WAV의 중역 에너지와 RMS를 작은 위치 변화로 더한다. 전경과 배경의 크기·위치가 서로 다르게 변해 시차가 생긴다.

초점 거리와 입자 깊이 차이에 따라 네 층으로 나누어 흐림을 적용한다. 같은 입자의 분산량이 약 0.035부터 커졌다가 작아지며, 뭉칠 때는 작은 분기가 드러나고 흩어질 때는 증기처럼 흐려진다. 이는 확산 모델 이미지 생성이 아니라 절차적 입자 이동과 광학적 흐림이다.

마지막에는 기존 푸리에 물결 고리로 점들이 다시 모인다. 달은 먼 공간의 기준점으로 유지한다. 화면의 모든 배경 요소까지 한 물체로 합치는 것은 아니다.

## 실제 시안에서 수정한 것

첫 시안은 너무 어두웠고, 입자별 분산이 미세 구조보다 커서 균일한 먼지장처럼 보였다. 대표 군집의 대비를 높이고, 응집 순간의 분산을 낮추고, 초점 안 입자의 흐림을 줄였다. 비평 담당은 수정 후 큰 군집 내부의 작은 밀도 구조와 확산 상태의 대비가 읽힌다고 판단했다.

[독립 비평](vapor-critique.md). 이 판정은 정지 시안의 본편 렌더 진행 가능 여부이며 직접 청각 승인이나 10분 연속 시청 만족을 뜻하지 않는다.

## 제작 경로

```sh
pnpm nx run media:vapor-score
pnpm nx run media:vapor --audio
pnpm nx run media:vapor --stills
pnpm nx run media:vapor
```

기본 산출 폴더는 `runs/dp-sts-vapor-base-v02`. 기존 음원·영상이 있으면 덮어쓰지 않는다. 최종 Hydra 처리는 새 WAV, 새 영상, 새 대역 분석과 Strudel 선율 이벤트를 입력한다. 기존 Hydra 패치의 시간 연속 피드백을 유지하되 새 공간의 초점·시차가 사라지지 않는지 확인한다.
