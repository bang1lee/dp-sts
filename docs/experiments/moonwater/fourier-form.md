# 빛의 분화가 하나의 형상으로 귀결되는 규칙

사용자 디렉션: “푸리에 방정식이 수학적으로 귀결되어 모든 오브제들이 정렬되며 형상을 띄는 형식으로”.

## 이번 작품의 수학적 해석

하나의 닫힌 물결 고리를 복소 평면의 곡선으로 정의한다.

\[
z(\theta)=\left(1+0.065\cos(3\theta)+0.025\sin(5\theta)\right)e^{i\theta}
\]

이 곡선을 768개 점으로 표본화하고 DFT로 계수 \(c_k\)를 구한다. 필요한 주파수 모드는 \(k\in\{-4,-2,1,4,6\}\)다. 푸리에 합성은 다음과 같다.

\[
z_j(t)=\sum_k c_k\exp\left(i\left[k\theta_j+(1-a(t))\delta_{j,k}\right]\right)
\]

각 조각의 위상 편차 \(\delta_{j,k}\)가 서로 다르므로 처음에는 하나의 윤곽으로 보이지 않는다. 정렬 정도 \(a(t)\)가 0에서 1로 움직이면 편차가 사라지고, 모든 서사적 빛 조각이 동일한 곡선 위의 자기 위치를 찾는다. 추가 위치 분산도 같은 비율로 감소한다.

정렬 시간은 350–555초다. 단순한 직선 이동의 급격한 시작과 종료를 피하려고 \(a=3u^2-2u^3\), \(u=\operatorname{clamp}((t-350)/205,0,1)\)을 쓴다. 달 주변으로 가로·세로 축척을 달리한 후 화면에 투영한다.

## 감각으로 읽는 법

- **분화:** 각 조각이 서로 다른 위상을 가져 원래 전체의 모습이 흩어져 보인다.
- **관계:** 위상 편차가 감소하면서 가까운 조각들이 국소적인 선과 곡률을 만든다.
- **귀결:** 처음부터 공통으로 가지고 있던 계수에 따라 하나의 물결 고리가 드러난다.

달과 수면은 이 정렬을 바라보는 환경으로 남고, 재구성 대상은 서사를 이루는 빛 조각들이다. 화면에 방정식이나 설명 자막은 넣지 않는다. 이 구분은 현재 구현 범위를 명확히 하기 위한 것으로, 사용자가 모든 환경 요소까지 통합하기로 확정한 뜻은 아니다.

수치 검증에서 위상 편차가 0일 때 목표 곡선과 합성 결과의 최대 오차는 약 \(6.28\times10^{-16}\)이었다. 곡선 재구성은 확인했지만, 이것만으로 전체 화면의 미적 완성도가 증명되는 것은 아니다.
