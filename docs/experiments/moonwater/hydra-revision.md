# dp-sts · Strudel 패턴과 Hydra 반응형 재렌더

2026-11-02. 사용자 요청에 따라 기존 작품을 검수하고 실제 Strudel·Hydra 연결로 다시 렌더한다.

## 검수에서 확인한 기존 상태

직전 아베 마리아 버전은 공개 MIDI 선율을 Python으로 합성하고 OpenCV 영상의 밝기를 근사 재매핑했다. 그 수정본에 새 Strudel 질의나 Hydra 렌더는 없었다. 음악은 600초 저음 선율이며 68.76초부터 선율이 시작된다. 이 사실을 도구 이름만 바꾸어 설명하지 않는다.

## 이번에 실제로 바뀐 경로

```text
공개 악보의 121음 → Strudel 가중 mini-notation → queryArc로 실제 패턴 이벤트 추출
                                              ↓ 음정·타이밍 대조
기존 저음 선율 WAV ──────────────────────────────┤
       ↓ RMS·FFT 대역 분석                     ↓ 음높이·프레이즈 진행
       └───────────────────── Hydra 제어값 ─────┘
기존 달빛·푸리에 영상 → Hydra 소스 텍스처 → 왜곡·이전 프레임 피드백·반복 → 새 MP4
```

Strudel 이벤트 121개의 음정은 기존 음악 제작 이벤트와 모두 일치했다. 시작·길이의 최대 차이는 약 `5.68e-14`초다. 따라서 사용자가 요청한 낮고 느린 선율의 기존 WAV를 그대로 사용한다. 이번 작업은 **Strudel 패턴의 실제 변환·검증·영상 제어 연결**이며, 오디오를 Strudel 신시사이저로 새로 합성한 작업은 아니다.

Hydra는 `hydra-synth 1.4.0`을 pnpm으로 설치해 실제 브라우저 GPU에서 실행했다. 오프라인 렌더이므로 마이크는 요청하지 않는다. WAV를 미리 분석한 값을 프레임 시간에 맞춰 공급한다. 벽시계나 실시간 재생 속도에 의존하지 않고 프레임마다 `tick(1000/24)`를 호출한다.

## 반응 관계

| 음악 정보 | 화면의 변화 | 절제 방식 |
|---|---|---|
| 35–90Hz 저음 | 수면의 느린 공간 왜곡 | 변위 상한, 후반 감쇠 |
| 90–250Hz 선율 에너지 | 이전 프레임 잔상과 작은 확대 | 피드백 혼합 상한 |
| 250–1500Hz 배음 | 잔상의 미세한 굴절 | 작은 변위 |
| Strudel 음높이·음 진행 | 빛 복제의 크기·배치·양 | 분화 구간에서만 증가 |
| 470–560초 통합 구간 | 왜곡·확대 강도 감소 | 마지막 푸리에 고리 식별성 보존 |

FFT는 8192샘플, 프레임 간격은 2000샘플이다. 각 제어값은 0.22초 상승·2.4초 이완으로 부드럽게 연결한다. RMS도 기록하지만 이번 Hydra 패치의 주된 제어는 대역 에너지와 Strudel 이벤트다. 원본 영상에 있던 밝기 반응은 남아 있으므로 전체 화면이 Hydra만으로 처음부터 생성됐다고 주장하지 않는다.

## 확인한 증거와 한계

- 300–312초 시안: 실제 Hydra 실행, GPU는 Apple M1 Max의 ANGLE Metal, JS 오류 없음.
- 동일 구간에서 신규 오디오·패턴 제어값을 0으로 만든 대조 시안과 비교했다. 312초 프레임의 RGB 평균 절대 차이 `3.5855/255`, 차이가 3을 넘는 픽셀 비율 약 `38.4%`로 신규 반응의 작동을 확인했다. 이는 미적 점수나 청각 평가가 아니다.
- 중반·결말 시안은 각각 8초 피드백 워밍업을 사용한다. 시안의 초기 상태가 0초부터 연속 렌더한 본편의 전체 이력과 같다고 보장하지 않는다.
- 본편은 0–600초를 한 Hydra 인스턴스로 연속 렌더해 피드백 이력을 유지한다.
- 음악 직접 청취 승인은 별도다. 기술 검사·표본 시각 비평을 전체 예술적 승인으로 확대하지 않는다.

## 재실행

프로젝트 루트에서:

```sh
pnpm nx run media:hydra-score
pnpm nx run media:hydra-features
pnpm nx run media:hydra-render --start=300 --duration=12 --out=runs/hydra-new-preview
pnpm nx run media:hydra-render --out=runs/hydra-new-full
```

출력 폴더가 이미 존재하면 중단하여 기존 작품을 보존한다. 이 도구는 최종 영상을 만드는 오프라인 렌더 작업이며 새 사용자용 웹 UI를 추가하지 않는다.

공식 참고: [Hydra 합성 엔진](https://github.com/hydra-synth/hydra-synth), [Strudel의 Hydra 연결](https://strudel.cc/learn/hydra/).
