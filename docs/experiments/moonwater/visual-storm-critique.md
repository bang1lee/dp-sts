# Organic Storm — 7편 시각 비평

상태: **Terra v03의 01–05·07 정지 시안 수용 · 06 강도 보강 후 재확인 · 각 180초 본편 검토는 별도**.

## 요청과 범위

자연색의 유기적 프랙털 액체·선 5편과 강한 사이키델릭 2편, 각각 180초를 검토한다. 기존 작품을 보존한 별도 시리즈다. 이 비평은 실제로 본 이미지·프레임 근거에 한정하며, 음악을 직접 듣거나 전체 영상을 연속 시청했다는 주장을 하지 않는다.

제작 방향 문서 `visual-storm.md`와 `tools/storm-scenes.mjs`를 읽었다. 숲·산호·빙하·균사·광물은 서로 다른 물성의 해석이며, 실제 자연 관측 데이터나 물리 유체 시뮬레이션의 결과라고 판단하지 않는다. 음원은 기존 Folktronica Bloom과 psytrance의 발췌이므로 일곱 곡의 신규 작곡으로 표현하지 않는다.

## 평가 기준

| 기준 | 원하는 결과 | 수정이 필요한 징후 |
|---|---|---|
| 5편의 자연색 | 숲의 녹색·산호색·빙하색·균사의 어둠·광물색이 서로 다른 물성을 만듦 | 같은 형상에 팔레트만 교체, 전부 비슷한 갈색·녹색으로 수렴 |
| 유기적 연결 | 큰 굴곡과 작은 결이 이어지고 액체의 접힘 또는 선의 관계가 읽힘 | 균일 노이즈, 형태와 무관한 색 띠, 고정된 패턴 벽지 |
| 형태 차별성 | 안료 접힘·나선 패각·긴 전단·필라멘트·퇴적 등고선이 구분됨 | 제목을 가리면 작품을 구분하기 어려움 |
| 규모와 위계 | 큰 형태와 가까이서 볼 미세한 선이 함께 있고 여백이 있음 | 모두 같은 선폭, 미세한 고주파만 가득, 작은 화면에서 뭉개짐 |
| 강한 2편의 대비 | 터널의 안쪽 깊이와 꽃의 방사형 개화가 서로 다름 | 둘 다 비슷한 만화경, 채도만 높여 강도를 주장 |
| 강도의 질 | 선의 변형·채도·깊이에서 밀도가 생김 | 전체 화면의 무차별 밝기 점멸이나 지속 포화 |
| 180초의 전개 | 시작·발전·절정·종결이 실제 출력에서 드러남 | 짧은 시안만 승인하고 3분 전체의 변화를 보았다고 주장 |

## 실제 관찰

### 초기 미리보기 — 7편 실제 확인

각 디렉터리의 `preview-072.jpg`를 실제로 확인했다. 이는 72초 정지 시안이며 4초 영상이나 전체 180초를 연속 시청한 판단이 아니다.

| 작품 | 관찰 | 초기 판단 |
|---|---|---|
| Canopy Melt | 짙은 녹색·잎색·금색 안료가 접히는 마블링. 큰 덩어리는 읽히나 작은 선이 거칠게 조밀함 | 자연색은 적합. 미세 결을 줄여 물성과 위계 개선 권고 |
| Coral Vortex | 산호빛 나선과 패각형 주름의 방향성이 명확하나 왼쪽에서 중심으로 수평 접합선이 보임 | 접합선 수정 필수 |
| Glacier Veins | 청록·남색은 분명하지만 01과 비슷한 전면 마블링 소용돌이 | 길게 휘는 틈·띠로 형태 분리 권고 |
| Mycelium Choir | 어두운 바탕에 금색·청록 필라멘트가 연결되며 굵기와 밝기 차이 존재 | 선 계열로 분명히 차별화. 추가 필수 수정 없음 |
| Mineral Memory | 모래·녹청·적갈색 물성은 좋으나 01·03과 같은 마블링 규모 | 큰 지층과 낮은 빈도의 등고선으로 분리 권고 |
| Neon Abyss | 중심 구멍과 재귀적 곡선이 있으나 왼쪽 수평 접합선과 전면의 고밀도 색 잡음 존재 | 접합선 수정 필수. 큰 곡선 대비를 남기고 미세 잡음 완화 권고 |
| Acid Bloom | 검은 여백 안에 밝은 라임·분홍의 방사 구조와 작은 반복 꽃이 명확 | 06의 터널과 다른 개화 방향. 추가 필수 수정 없음 |

제작 담당도 02·06의 각도 좌표 접합선과 01·03·05의 형태 중복을 확인했고 v02를 준비 중이라고 밝혔다. 최종 렌더 진행 판단은 개선 시안에서 접합 해소와 형태 차별화를 확인한 뒤 내린다.

### v02 — 일곱 편 재확인

각 디렉터리의 `preview-v02-072.jpg` 일곱 장을 실제로 확인했다. 초기본은 보존하고 새 파일을 기준으로 비교했다.

- **01 숲:** 거칠고 가는 잡음이 줄면서 녹색·상아·금빛 안료의 큰 접힘과 매끄러운 질량이 더 잘 읽힌다.
- **02 산호:** 왼쪽 수평 접합이 사라졌다. 따뜻한 산호색과 암부가 나선 패각의 연속된 방향성을 만든다.
- **03 빙하:** 작은 소용돌이들이 길게 휘는 청록의 띠와 가는 경계선으로 바뀌어 01과 형태가 뚜렷하게 구분된다.
- **04 균사:** 금색·청록 필라멘트의 밀도와 어두운 여백이 유지된다. 다른 액체 계열과 구분되는 선 중심의 작품이다.
- **05 광물:** 넓은 모래·녹청·적갈색 지층과 낮은 빈도의 등고선이 나타나 01·03과 중복되던 문제가 해소됐다.
- **06 심연:** 수평 접합이 사라졌다. 미세 색 잡음이 여전히 많지만 중심의 어두운 입구와 외곽의 재귀적 격자·곡선이 안쪽으로 향하는 공간을 만든다. 이 밀도는 표현상 한계로 남기되 현재 프레임에서 추가 렌더 차단 사유로 삼지는 않는다.
- **07 개화:** 검은 여백과 밝은 방사형 반복 꽃이 유지된다. 06의 전면 터널과 달리 바깥으로 꽃피는 성격이 분명하다.

**미리보기 단계 판단: 일곱 편 모두 본편 렌더 진행 가능.** 필수 접합 결함과 자연 계열 세 편의 형태 중복이 해결됐다. 다섯 자연 작품은 팔레트뿐 아니라 큰 형태의 규칙에서도 구분되며, 강한 두 작품은 채도·미세 반복·중심 구조에서 자연 계열과 대비된다.

이는 72초 정지 프레임 각각에 대한 판단이다. 각 180초의 서사, 실제 속도에서의 편안함과 번쩍임, 음원과의 감각적 관계를 확인한 것으로 확대하지 않는다. 음악 직접 청취는 수행하지 않았다.

### Terra v03 — 72초·75초, 총 14장 독립 검토

각 작품의 `preview-terra-v03-072.jpg` 및 `preview-terra-v03-075.jpg`를 실제로 확인했다. 앞선 v02 수용을 그대로 이전하지 않고 새 출력으로 판단했다.

**01–05와 07은 본편 렌더 진행 가능.** 숲의 안료 접힘, 산호의 나선, 빙하의 긴 띠, 균사의 필라멘트, 광물의 큰 지층이라는 차별성이 유지된다. 확인한 두 시점에서 접합선 재발이나 화면 전면의 과도한 미세 잡음은 보이지 않는다. 07은 중심과 방사형 반복 구조, 작은 선의 복잡함, 라임·분홍·보라의 대비가 강한 사이키델릭 방향을 유지한다. 이 여섯 편에는 추가 필수 수정이 없다.

**06은 강한 두 편 중 하나라는 목표에 맞춰 한 차례 보강 권고.** v03은 v02의 과밀한 미세 색 잡음을 제거하고 큰 터널 구조를 만들었으나, 실제 두 시점에서는 부드러운 보라·청색 리본 소용돌이로 읽힌다. 중첩된 재귀 선이 거의 사라져 07과 함께 ‘강한 사이키델릭 2편’을 구성하기에는 복잡도와 색 대비가 약하다. 이는 결함 수정 중 강한 정체성까지 약해진 사례로 판단한다.

권고는 현재 큰 어두운 터널을 유지하면서 중간 반경에 2–3개 공간 규모의 선명한 윤곽·접힘·재귀 기하와 cyan/magenta/lime 대비를 추가하는 것이다. v02의 전면 미세 잡음을 되돌리는 방식은 피한다. 제작 담당도 같은 약화를 확인하고 06만 재조정하기로 했다. 나머지 여섯 편의 진행을 막는 사유는 아니다.

검토 범위는 두 정지 시점의 형태·색·접합·과밀이다. 실제 속도의 4초 클립이나 180초 전체를 시청한 판단, 음악 청취 판단은 아니다.
