# 구조라 Continuum 30초 구현

클라이맥스 장면을 보존하고 해변과 바다를 주변 공간으로 이어 붙인 별도 버전이다. 기존 442,146점에 모래 250,000점, 외해 150,000점, 공기 중 안개 42,146점을 독립적으로 더해 총 884,292점이다. 각 점은 입체 공간에 고정된다.

인물이 앉은 해변에서 육지 방향으로 모래와 완만한 사구가 이어지고, 유목은 그 육지 쪽에 남는다. 파도와 모래의 경계에서는 기존 물 입자를 점차 어둡게 처리한다. 외해와 해변 입자는 넓고 불규칙하게 분포하며 주변으로 서서히 엷어져 직사각형 경계가 생기지 않도록 한다. 물은 차가운 색, 모래는 옅은 따뜻한 색으로 구분한다. 중앙 연무는 이전 클라이맥스 장면보다 옅게 조정했다.

추가 재질의 밝기는 위치에 따라 연결된 느린 함수로 변화한다. 저음 어택은 연무의 크기와 밝기에 반응하며, 입자의 위치는 이동하지 않는다. 카메라는 앞선 30초 경로를 이어받는다. 실제 결과에서 해변·섬·인물이 식별되는지와 연속적인 움직임은 스틸 및 영상 검수가 필요하다.

기본 720×720 영상은 내부 1440×1440, 24fps로 렌더한 뒤 축소한다. 원본과 두 단계 장면 의존성의 해시와 복사본, 실제 입자 수·그룹·공간 범위, 음원과 분석 해시, 카메라 정보를 `render.json`에 기록한다. `--bass-comparison`은 같은 시점의 실제 어택과 어택 0을 비교하는 진단 스틸을 만든다. 영상 생성과 스틸 출력은 기존 파일을 덮어쓰지 않는다.

```sh
pnpm exec node tools/gujora-continuum.mjs --stills-only --out=runs/dp-sts-gujora-continuum-stills-v01 --still-times=0,3,9,19,27,29.5 --bass-comparison
pnpm exec nx run media:gujora-continuum-render
```
