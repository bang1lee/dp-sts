# 구조라 클라이맥스 30초 구현

기존 464초 공간 버전의 장소와 카메라 서사를 30초로 재구성한 별도 버전이다. 오프닝의 섬·바다·해변에서 시작해 측면과 근접 공간을 통과하고, 클라이맥스 이후 원래 장소가 다시 나타난다. 키프레임은 시간 가중 3차 Hermite 보간으로 연결한다. 움직이는 카메라가 3차원 위치를 지나는 원근 영상이며, 입자 좌표는 고정한다.

- 원본 장면 221,073점과 추가 안개 221,073점으로 총 442,146점이다. 추가점의 40%는 기존 표면 주변, 50%는 카메라 경로를 감싸는 꼬인 연무, 10%는 더 넓은 공간에 독립적으로 분포한다. 복제점이 아니다.
- 격자 흔적을 낮추기 위해 원본 섬·물·섬 내부의 점에 작은 결정적 교란을 주고, 크기가 다른 부드러운 발광 입자를 사용한다. 반투명 입자는 깊이를 기록하지 않아 뒤쪽 입자에 검은 테두리를 만들지 않는다. 물의 높이는 고정하며 기존 GL 선분은 이 버전에서 그리지 않는다.
- 초당 24프레임, 기본 2160×2160으로 렌더해 Lanczos로 1080×1080으로 축소한다. `--size=720`을 지정하면 1440×1440에서 720×720으로 축소한다. 두 설정 모두 영상은 720프레임이며 검토용 PNG는 각 렌더 원본 크기다.
- 24fps 음원 대역 분석과 별도 50fps 저역 상승 어택을 WAV 해시로 확인해 사용한다. 어택은 안개와 화로 빛에 빠르게 반영되며 모든 프레임을 흰색으로 번쩍이게 하지 않는다.
- 시작·끝은 원래의 섬과 물, 7명, 화로, 별, 해변 유목을 재현하는 구도를 사용한다. 중간에는 근접 입자 공간을 허용한다. 장소는 제작상의 양식화된 해석이다.
- 실제 점 개수, 3차원 영역의 최소·최대 좌표, 카메라, 샘플링, 음원·분석·구현 해시, GPU 정보는 실행 후 `render.json`에 기록한다. 이는 학습된 Gaussian Splatting 재구성이 아니라 투영된 가우시안 모양의 입자다.

음원 입력은 `runs/dp-sts-gujora-climax-v01/`의 `audio.wav`, `audio-features.json`, `audio-attacks.json`이다. 스틸과 최종 영상은 덮어쓰기를 거부하며 서로 다른 폴더에 생성한다.

```sh
pnpm exec nx run media:gujora-climax-stills
pnpm exec nx run media:gujora-climax-render
```

`--bass-comparison`은 같은 시점의 카메라와 대역 값을 유지한 채 실제 어택과 어택 0을 비교하는 진단 PNG 두 장을 만든다.

스틸의 시각적 수용 여부와 실제 음향 반응은 렌더 및 독립 검수 결과로 판단해야 한다. 이 문서는 구현 설명이지 영상 완성이나 사용자 승인을 뜻하지 않는다.
