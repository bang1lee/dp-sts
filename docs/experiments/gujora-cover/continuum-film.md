# 구조라 — 이어지는 장면

> 후속 확정: 사용자가 ‘원음’은 Aphex Twin 「#3」의 실제 녹음이라고 명시했다. 아래 영상은 그 답변 전에 만든 자체 합성 음원 버전이다. 실제 녹음을 사용하는 음악 교체는 아직 완료되지 않았다.

## 사용자 디렉션

브라우저에서 선택한 30초 하이라이트 v01의 음악은 빠르지 않게 고친다. 모래사장의 디테일을 추가하고, 인지되는 중심 영역 바깥에도 같은 세계가 희미하게 이어져야 한다. 가장 넓은 앵글에서도 주변의 존재를 남기고, 입자 수를 늘리면서 디밍과 디퓨전을 섬세하게 표현한다. 기존 30초·720 출력 규격을 유지한다.

## 음악과 편집

선택된 v01 제작에 사용했던 압축 전 자체 합성 앰비언트 마스터의 50–80초를 원래 속도·음높이로 사용했다. 바흐 BWV 846 음형 기반의 기존 마스터이며 Aphex Twin 원음 녹음은 아니다. 0.8초 페이드인·2.5초 페이드아웃과 60BPM의 조용한 하이햇만 추가했다. 하이햇은 프로젝트 자체 샘플을 실제 Strudel로 초당 한 번 배치했으며, 킥·스네어·새 베이스는 넣지 않았다. 원음 스템과 하이햇 스템을 별도 보관했다.

먼저 FFmpeg로 기존 720 영상의 음악만 교체한 [편집본](../../../runs/dp-sts-gujora-audio-recut-v01/artwork.mp4)을 만들었다. 영상 스트림을 재인코딩하지 않았고 원본과 결과의 영상 해시가 동일하다. 이 편집본의 입자 반응은 기존 타임라인을 유지한다. Resolve 연결은 사용할 수 없어 Resolve에서 편집했다고 주장하지 않는다.

이후 이번 시각 수정까지 적용한 본편은 새 믹스에서 다시 추출한 저역·중역·고역·저음 어택을 사용한다. 시간 압축이나 음높이 변화는 없다. 청취 만족도와 참고곡의 동일한 질감 재현을 기술 검사로 판정하지 않는다.

## 공간·입자

실제 장면 점 수는 442,146개에서 884,292개로 늘었다. 추가된 점은 모래 250,000개, 외해 150,000개, 주변 안개 42,146개다. 새로운 모래는 작은 높낮이·잔능선·불규칙한 젖은 띠를 가지며, 수면보다 약간 따뜻한 명암으로 구분된다. 외곽 수면과 안개는 완만하게 어두워져 기존 이미지 영역의 사각형 끝을 완화한다.

좌표는 고정되며 원근 이동과 연속적인 조명 변화가 공간의 관계를 드러낸다. 중앙 안개의 기본 강도를 줄이고 전경의 큰 흐림을 낮춰 바닥 결을 남겼다. 다중 크기의 부드러운 입자와 1440→720 축소를 사용한다. 시간적 모아레의 완전한 제거를 보장하지 않는다.

첫 시안은 모래 결과 젖은 띠가 묻혀 반려했다. 국소 대비와 미세 능선을 보강한 두 번째 시안을 Astra가 실제 0·19·27·29.5초 이미지로 확인해 수용했다. 바다·섬·일곱 인물과 귀환 구조는 유지했다. [독립 검수](continuum-review.md).

## 출력과 검사

본편은 30.000초·720×720·24fps·720프레임, 48kHz 스테레오다. 전체 영상·음원 디코딩, 원음·하이햇 스템과 최종 믹스의 합, 음원 제어 데이터와 소스 스냅샷 해시를 확인했다. 영상 기술 검사와 미학적 승인, 직접 청취 검수는 별개다.

실행 대상은 `media:gujora-continuum-audio`, `media:gujora-continuum-render`, `media:gujora-continuum-verify`다. 기존 출력은 덮어쓰지 않는다. 첫 스틸의 코드 스냅샷 저장 오류는 두 번째 시안과 본편에서 수정·해시 확인했으며 첫 시안은 실패 이력으로 보존한다.
