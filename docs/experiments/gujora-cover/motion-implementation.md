# Gujora / Yundol — motion implementation

The accepted square white-line cover is the single visual source. Hydra samples it through a bounded coordinate field; there is no image generation, simulation of a physical shoreline, 3D reconstruction, or accumulated feedback. The region envelopes are approximate image-space art direction rather than a geographic segmentation.

The land holds its outline with a small slow breathing movement. The ocean receives overlapping broad and finer horizontal currents, concentrated near the shoreline and attenuated at the image margins. The first 45 seconds remain quiet; the current grows into the middle section and eases back toward the original cover between 135 and 180 seconds. The smoothed low, middle, and high frequency bands from the supplied recording modestly influence displacement. The same audio smoothing is computed from the start for preview and full render, so a given frame uses the same controls in both.

The input is loaded once as Hydra `s0`; output is a 1080 × 1080, 24 fps square. A GPU-generated coordinate probe and comparison against the input check screen and texture orientation before rendering. The zero-motion image is checked again after correction. PNG frames are streamed into H.264 encoding to keep the original thin lines clear; the supplied WAV is paired with the selected interval. The script refuses to overwrite its output video. It writes the implementation and image/audio/analysis hashes, timing, orientation measurements, selected actual rendered stills, and runtime errors alongside each successful export.

Full render: `node tools/gujora-film.mjs`; eight-second preview beginning at 72 seconds: `node tools/gujora-film.mjs --preview`. `--out=...` chooses the output directory, `--input=...` chooses the directory containing `cover.png`, `audio.wav`, and `audio-features.json`, and `--still-times=...` selects comma-separated, frame-aligned seconds inside the chosen interval. The default full stills are 15, 60, 90, 135 and 165 seconds. A preview and full render must be inspected before claiming visual or performance results.
