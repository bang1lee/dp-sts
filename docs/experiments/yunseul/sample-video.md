# 전체론적인 체험 — 10초 코드 샘플

2026-10-31. 사용자 U006에 따라 실제 코드로 렌더링하는 첫 시안. 최종 미학의 확정이나 장편 제작은 아니다.

## 실행

```sh
pnpm nx run media:yunseul --output=runs/yunseul-sample-v01
```

새 실험은 새 출력 경로를 사용한다. 기존 폴더가 있으면 덮어쓰기를 거부한다. 대표 스틸만 확인하려면 새 경로와 `--preview`를 사용한다. 설정 파일은 `--config`로 지정할 수 있다.

Nx가 실행을 조율하고 uv가 기존 Python 패키지를 사용한다. 의존성 추가 없이 NumPy·OpenCV로 물결, 표면 방향, 3D 투영, 반사와 합성을 계산하고 FFmpeg로 인코딩한다. 기존 Strudel/Julia 파이프라인은 변경하지 않는다.

## 이번 샘플의 표현

- 1280×720, 30fps, 10초. 영상에는 텍스트나 게이지를 넣지 않는다.
- 카메라는 공간 안에서 옆으로 이동하며 조금 전진한다.
- 둥근 범위의 물결 조각들은 서로 다른 깊이·높이에 위치한다. 큐브 윤곽은 그리지 않는다.
- 실제 표면 방향과 카메라 방향의 관계로 반사 강도를 계산한다. 과학적 광학 시뮬레이터나 완전한 유체 시뮬레이션은 아니다.
- 서로 다른 크기의 중첩된 물결이 미세 구조를 만든다. Julia/Mandelbrot 프랙털이나 지정된 프랙털 차원을 계산한 것은 아니다.
- 연결성은 공유하는 공간 파형과 느린 파도 주기로 표현한다. 오브제간 충돌·힘의 전달은 아직 구현하지 않았다.
- 음향은 파도처럼 부풀고 가라앉는 합성 스테레오 노이즈다. 실제 바다 녹음이나 Strudel 음악 편곡으로 표현하지 않는다.

## 현재 설정

실제 값은 [sample.json](../../../compositions/yunseul/sample.json)에 있다.

| 설정 | 값 | 의미 |
|---|---:|---|
| density | 0.48 | 고정된 군집 안에서 유지할 표본 비율 |
| glint_amount | 0.24 | 반사의 강도·집중도를 조절하는 예술적 매개변수; 반짝이는 픽셀의 정확한 비율은 아님 |
| glint_rate | 0.22 | 느린 반사 허용 곡선의 초당 주기; 실제 반짝임 사건 수를 보장하지 않음 |
| flow_speed | 0.7 | 물결의 시간 변화 배율 |
| wave_period | 5.4초 | 시각·음향이 공유하는 큰 파도의 주기 |
| audio_latency | 0.3초 | 공통 파도 곡선에 대한 음향 강도 곡선의 지연 |
| audio_sync | 0.85 | 공유 곡선과 독립 곡선의 혼합 비율 |
| camera_travel | 2.4 | 카메라의 가로 이동량, 장면 좌표 단위 |

세 군데 시점과 게이지를 담은 `review-board.jpg`는 실제 렌더 프레임과 설정으로 만든 검토 이미지다. 대화형 조절 UI는 아니다. 영상 프레임과 별도로 제공한다.

## 검증과 한계

첫 출력: [10초 영상](../../../runs/yunseul-sample-v01/film.mp4), [설정·대표 프레임](../../../runs/yunseul-sample-v01/review-board.jpg), [검증 결과](../../../runs/yunseul-sample-v01/verification.json). `runs/`는 로컬 산출물 폴더로 버전 관리에서 제외되어 있다.

실제 결과: 10.000초, 1280×720, 30fps, 300프레임 전체 디코딩 성공, 고유 프레임 300개, 2채널 오디오. 렌더·검증에 약 73초가 걸렸다. Python 검사와 기존 검증을 포함한 15개 테스트가 통과했다. 대표 프레임은 직접 열어 확인했다. 청음에 의한 음색 평가는 아직 별도로 확인하지 않았으며, 주관적 완성도와 컨셉 적합성은 사용자 확인 전이다.

표면의 미분과 법선, 카메라 좌표계, 음향 지연, 오디오 길이·여유 레벨, 잘못된 입력 거부를 테스트한다. 출력 후 전체 프레임 디코딩, 프레임 수, 크기, 길이, 실제 영상 변화와 스테레오 트랙을 검사한다. 결과는 출력 폴더의 `verification.json`과 `render.json`에 남긴다.

지금은 실제 관람자 입력에 반응하는 설치물이 아니며, 고정된 카메라 경로를 렌더한 영상이다. 기술 검증은 사용자 감상이나 섬광 안전성 인증, 생리학적 효과의 검증을 대신하지 않는다. 샘플의 질감은 입자 기반 추상 표현이다.
