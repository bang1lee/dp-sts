# 윤슬 컨셉 문서

현재 단계는 **가능성을 제안하고 의견을 수렴하며 결정을 추적하는 컨셉 고도화와 10초 코드 샘플 검토**다. 사용자 U006이 기존 문서 전용 범위를 이번 샘플에 한해 갱신했다. 컨셉·결정은 Markdown으로 유지하고, 코드 샘플의 근거와 실제 출력은 별도로 연결한다.

현재 컨셉은 **전체론적인 체험**이다. 바다의 물결감과 윤슬 군집을 입체 공간에 띄우고, 시점 변화와 오브제의 관계, 파도 소리의 지연을 함께 탐색한다. 장기적으로 약 10분을 염두에 두지만 이번 출력은 10초다. 감각의 적합성은 사용자 확인 전이다.

과학 근거는 작품의 생리학적 주장과 관람 조건을 검토하는 토대다. 특정 주파수의 송과체 정렬이나 이 작품의 멜라토닌·신경가소성 향상은 검증된 효능으로 채택하지 않는다. 이 판단으로 예술적 의미를 대신 정의하지도 않는다.

새 의견은 원문과 해석을 구분해 기록한다. 선택되지 않은 안은 자동 폐기하지 않으며, 미응답을 동의로 처리하지 않는다. 다음 작업 역시 새 디렉션에 따라 문서를 발전시키는 것이다.
