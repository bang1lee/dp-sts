## 주장별 판정

| 주장 | 관련 근거 | 현재 판정 |
|---|---|---|
| 빛의 조건이 멜라토닌 리듬에 영향을 준다 | S01–S04 | 생리학 근거 있음. 개인·장치·시간 조건 필요 |
| 특정 음악·영상 주파수로 송과체를 정렬한다 | S05–S09와 해당 경로 검토 | 이번 작품에 채택할 검증된 방법을 확인하지 못함 |
| EEG 동조가 장기 신경가소성 향상을 뜻한다 | S05–S07, S10 | 다른 측정과 시간척도이므로 자동 추론 불가 |
| 타액 표지자의 변화가 뇌의 지속적 재구성을 입증한다 | S09 | 연구 자체의 측정·한계를 넘어서는 주장 |
| 평온과 아름다움은 하나의 고정된 자극으로 최적화할 수 있다 | S11–S12 | 해당 연구들이 지지하지 않음. 사용자 경험을 별도로 탐색 |
| 윤슬을 공간적 분열·흔적·지연으로 표현한다 | 사용자 방향과 에이전트 제안 | 과학적 사실이 아니라 열린 창작 가설 |

‘근거를 확인하지 못함’은 존재 불가능의 증명이 아니다. 이 표는 표적 문헌 검토이며 전체 문헌을 망라한 체계적 고찰이 아니다.
