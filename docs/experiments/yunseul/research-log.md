# 조사와 문서 검토 기록

날짜: 2026-10-31 (Asia/Seoul).

## 목적과 범위

사용자 감각을 보존하면서 빛·멜라토닌·송과체·신경가소성·미적 경험의 근거를 구분한다. 현재 산출물은 Markdown 컨셉 문서다. 구현, 하네스 구성, 건강 상태 추론, 임상 실험, 음악·영상 생성은 수행하지 않았다.

## 조사 방식

웹 검색과 원문 열람으로 일차 인간 연구를 우선 확인하고, 생리 경로에는 Endotext, 광환경에는 전문가 합의문, 섬광에는 W3C 공식 문서를 사용했다. 검색 주제는 pineal melatonin retinal SCN pathway, light exposure melanopic EDI, 40 Hz sensory stimulation randomized trial, binaural beats melatonin, 432/528 Hz BDNF CREB, neuroplasticity training, aesthetic experience individual differences였다. 이는 검색 주제 요약이며 검색 호출 원문의 완전한 기록은 아니다.

긍정적 타액 지표 결과와 효과가 확인되지 않은 EEG 결과를 함께 검토했다. 상업적인 치유 주파수 주장이나 영상 홍보를 효능 근거로 채택하지 않았다. 2026년 발표 자료도 확인했다. Context7은 사용하지 않았다.

## 열람 한계

- S01은 일반 NCBI 경로의 접근 제한 후 대체 공식 경로에서 본문을 확인했다.
- S04는 PNAS 접근 제한 및 PMC 확인 화면 때문에 초록과 공개 발췌만 사용했다.
- S06은 출판사 공개 초록만 확인했으며 전체 유료 본문을 읽었다고 주장하지 않는다.
- S08은 PubMed 초록 범위다. 본문의 유의성이나 수치를 추정하지 않았다.
- S10은 출판사 리디렉션 제한과 별도 PDF 접근 실패로 공개 초록·색인 범위만 사용했다.
- 나머지 출처의 실제 열람 범위는 [근거 대장](evidence-ledger.md)에 명시했다.

전체 데이터베이스의 재현 가능한 전수 검색, 정식 편향 평가, 메타분석은 수행하지 않았다. ‘송과체 정렬의 근거를 확인하지 못했다’는 결론은 이 조사 범위에 한정된다.

## 문서 검토

- 사용자 원문과 에이전트 해석을 분리했다.
- 사용자 결정과 미결인 제안을 [결정 기록](decisions.md)에 구분했다.
- 근거마다 자료 유형과 실제 열람 범위를 적었다.
- 출력 프롬프트 본문에는 의학적 효능·뇌 도식·연구 수치를 넣지 않았다. 문서 전체를 시각 생성 입력으로 쓰도록 지시하지 않는다.
- 자동 실행 설정을 제안하던 초안은 협업 방식 문서로 수정했다. 이번 컨셉 작업의 변경 대상은 Markdown뿐이다.
- 검토는 작성 에이전트의 자체 검토다. 독립 연구자 검증이나 임상 검수로 표현하지 않는다.

영상·음향이 생성되지 않았으므로 실제 눈부심·섬광·음량·미적 완성도·10분 지속성은 아직 평가할 수 없다.
