# dp-sts 작품 보관함

스튜디오 개발 서버에서 [작품 보관함](http://localhost:4200/gallery.html)을 연다. 서버가 꺼져 있다면 프로젝트 루트에서 `pnpm exec nx serve studio`로 실행한다. 같은 컴퓨터에서만 접근하며 외부에 게시하지 않는다.

프로젝트의 `runs/` 아래 비어 있지 않은 영상·음원·이미지를 작업별로 읽어 목록에 표시한다. 비주얼 스톰은 일곱 장면을 개별 작업으로 보여준다. 검색과 유형 필터, 상세 창의 파일 목록과 연결된 검토 문서로 결과를 살펴볼 수 있다. 이미지가 많은 작업은 파일 목록을 나누어 보여주며 영상과 음원은 사용자가 선택한 것만 불러온다. 작품 목록은 20초마다 갱신하고 새로고침 버튼으로 즉시 다시 읽을 수 있다. 갱신 중 재생하고 있던 작품은 다시 불러오지 않는다.

상태는 결과물과 명시적으로 확인된 사용자 피드백을 구분한다. `제작 진행 중`은 최종 렌더가 아직 준비되지 않은 작업, `기술 점검 기록 있음`은 작품에 대한 기존 검증 기록이 있는 작업, `이전 시안 · 재작업 필요`는 불수용된 시안이다. 갤러리는 매번 대용량 영상의 해시를 다시 계산하지 않으므로 기록 이후 파일이 바뀌었는지 판단하지 않으며, 기술 점검 기록은 사용자의 작품 승인이 아니다. 그 외에는 `감상 확인 전`으로 둔다.

구조라 7분 44초 버전에는 사용자가 무아레 개선을 요청한 이전 버전임을 표시한다. 새 30초 버전은 준비 중으로 표시하며, 최종 영상의 렌더 기록이 생기기 전에는 작성 중인 영상 파일을 재생 목록에 올리지 않는다. 렌더 후 실제 디코딩 검증 기록이 생기기 전에는 `최종 검증 대기`로 표시한다.

목록 API와 파일 전달은 읽기 전용이며 프로젝트 내부 결과물과 관련 검토 문서만 제공한다. 경로 이탈과 심볼릭 링크를 통한 접근을 차단하고, 영상 탐색을 위한 부분 요청을 지원한다. 원본 파일은 수정하지 않는다. 목록이 안전 상한에 도달하면 화면에 일부 누락 경고를 표시한다. 서버 플러그인은 스튜디오 개발 서버에서만 동작한다.

## 브라우저 확인 기록 · 2026-11-03

- 실제 갤러리 화면에서 ‘윤돌섬’ 검색, 관련 버전 목록, 이전 464초 버전의 수정 요청 표시, 제작 중인 30초 버전 표시를 확인했다.
- 완료된 영상의 상세 창을 열고 Escape로 닫는 동작을 확인했다. 확인 당시 브라우저 콘솔 오류는 없었다.
- 서버 부분 파일 요청·HEAD·경로 제한 검사와 스튜디오 빌드·타입 검사가 통과했다.
- `expect-cli` 자동 브라우저 검사는 두 번 시도했으나 실행 결과 없이 대기했다. 두 번째 실행에서 외부 측정 서버 연결 시간 초과 로그가 있었으며, 실제 정체 원인은 확정하지 않았다. 접근성·성능 자동 검사 통과로 보고하지 않는다. 직접 확인한 UI 동작과 자동 검사 미완료를 구분한다.
