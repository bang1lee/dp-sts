# 음악을 유지하며 맨델벌브 연출하기

이 도구는 dp-sts 레시피 작품의 시각 연출을 조절한다. 음악의 빠르기·길이·악기·드럼은 유지하며, 맨델벌브의 형상과 관찰 방법을 바꾼다.

## 시작하기

1. 현재 열어 둔 제작 화면 `http://localhost:4300/recipe-film.html`을 연다. 이는 고정 빌드 미리보기다. 서버가 꺼졌다면 저장소에서 `pnpm nx build studio` 후 `pnpm nx run studio:preview --port=4300`으로 시작한다. 개발용은 `pnpm dev`와 `http://localhost:4200/recipe-film.html`이며, 코드 수정 중에는 화면이 새로고침될 수 있으므로 설정을 파일로 저장한다.
2. 음악 준비 전에는 무음 화면 재생과 시간 탐색으로 형태와 움직임부터 살핀다. 실제 음악 반응을 보려면 **음악 준비** 후 재생한다.
3. **원본**, **느린 회전**, **올라가는 호**, **표면 가까이** 중 하나에서 시작한다.
4. 한 번에 한두 항목만 바꾸고, 같은 재생 위치에서 비교한다. 마음에 드는 장면은 PNG로 남긴다.
5. **방향 설정 저장·전달**에서 **설정 JSON 저장**을 누른다. 이 파일을 채팅에 첨부하고 아래 출력 요청문을 함께 보낸다.

## 감각과 조절값 연결하기

| 원하는 인상 | 먼저 조절할 항목 | 살펴볼 것 |
|---|---|---|
| 같은 구조에서 다른 형상을 발견하기 | 형상 차수 | 반복되는 돌출부의 수와 표면의 결이 바뀐다. 값이 크다고 항상 더 아름다운 것은 아니다. |
| 구형에서 길쭉한 오브제로 이동하기 | 세로 늘림 | 실루엣을 먼저 비교한다. 근접 장면에서는 화면 밖으로 벗어날 수 있다. |
| 살아 있는 물체처럼 천천히 변화하기 | 변형 폭·변형 속도 | 폭은 얼마나 바뀌는지, 속도는 얼마나 빨리 바뀌는지를 뜻한다. |
| 관찰자는 머물고 물체만 움직이기 | 오브제 회전·회전 속도 | 카메라 속도를 낮추고 물체의 회전만 비교한다. |
| 오브제 주위를 둘러보기 | 카메라 경로·이동 속도 | 표면 가림과 빛이 달라지는 방식에 주목한다. |
| 미시세계와 거시세계 오가기 | 거리·화각 | 거리는 관찰 위치, 화각은 보이는 범위다. 근접할수록 전체 실루엣이 잘릴 수 있다. |
| 프레임 한쪽에 여백 만들기 | 바라보는 위치 | 중심을 조금 옮겨 구도를 잡는다. |
| 밝은 영역이 부드럽게 퍼지기 | 번짐 | 번짐이 너무 크면 표면의 세부가 약해질 수 있다. |

이 값은 하나의 정답을 정하기 위한 점수가 아니다. 같은 프리셋에서도 음악을 듣고 시점을 바꾸며 발견하는 도구다.

## 출력 요청문

```text
첨부한 dp-sts 방향 설정 JSON으로 영상을 출력해줘.
기존 dp-sts 음악과 드럼 킷, 음악 길이는 그대로 유지해.
맨델벌브 렌더링 방식도 유지하고, 형상·오브제 변화·카메라·색·번짐·음악 반응은 첨부값을 사용해.
JSON에 기록된 해상도와 30fps로 출력하고, 미리보기와 같은 시간 계산을 사용해.
새 설정을 임의로 추천하거나 덮어쓰지 말고, 먼저 첨부값을 검사해줘.
원본 음악과 영상의 시작 시점·길이·마지막 프레임을 확인한 MP4와 사용한 JSON을 함께 전달해줘.
```

## 파일에 담기는 것과 담기지 않는 것

설정 JSON은 연출값·출력 크기·30fps·기준 음악 정보와 출처 식별값을 담는다. WAV나 프랙탈 엔진 자체를 담는 파일은 아니다. 같은 프로젝트와 해당 음악 소스가 필요하며, 다른 음악 설정이나 지원 범위 밖 값은 불러오지 않는다.

미리보기와 영상 출력은 같은 시간 기준으로 계산한다. GPU·브라우저·영상 압축이 달라지면 픽셀이나 압축 파일이 바이트 단위로 같다는 보장은 없다.

현재 도구는 한 오브제의 연속 연출이다. 여러 컷을 자유롭게 편집하는 타임라인이나 임의 경로를 손으로 그리는 카메라 편집기와는 기능 범위가 다르다. 그런 연출이 필요하면 이 설정을 출발점으로 별도 컷 구성을 추가한다.
