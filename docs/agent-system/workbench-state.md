## 추가 요청: 확장 제안 반영 — 검증 완료

- Terra 엔진 담당: 실제 합성에 사용한 이벤트에서 공통 음악 JSON 출력. 기존 `offline.ts`에 이벤트 반환 메타데이터만 추가하고 합성·시간 예약은 보존한다.
- Terra UI 담당: 음악 JSON 다운로드, 확장 도구 안내·공식 링크, 실행 상태와 계획의 구분, 입력→대상 매핑 계획, v1 호환 v2 레시피 저장/복원.
- Astra: 실제 생성 이벤트와 문서의 일치, 오래된 음원/설정 혼용 방지, 잘못된 레시피의 원자적 거부, 계획을 실행 기능으로 오해시키지 않는지 변경 범위만 검수한다.
- 공통 데이터는 곧바로 Tone.js/Verovio가 읽는 네이티브 형식이 아니다. 각 실행 어댑터·악보 변환은 별도 구현 경계로 명시한다. 분석과 음악 스케줄링을 하나의 블로킹 루프에 합치지 않는다.
