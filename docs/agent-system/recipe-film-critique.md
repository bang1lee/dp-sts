# 레시피 기반 89초 작품 — 독립 검수

검수자: `workbench_critic` / Astra. 구현은 Terra 담당, 실제 브라우저 조작은 총괄 담당이다. 기존 작업대 수용과 별개의 작품 검수다. 사용자 레시피는 `runs/recipe-film-v01/source-recipe.json`으로 보존했다.

목표: 89.4332732399575초, 73.2085240142375 BPM, D3, mysterious의 음악과 원본 샘플 드럼을 사용하며, 실제 3D Mandelbulb 깊이와 음악에 반응하는 다양한 색을 가진 영상을 출력한다. 장르 참고는 잘게 나눈 리듬·변칙 악센트·여백의 독자적 구현이며 특정 아티스트 녹음이나 복제물을 쓰지 않는다.

## 1차 실제 출력 판정

**음원 기술·출처 확인: 통과. 시각 반응·색 다양성: 수정 필요. 완성 영상: 아직 미검증.**

검사자가 직접 읽은 대상: `runs/recipe-film-v01/music.wav`, `analysis.json`, `kit.json`, `source-recipe.json`, 네 PNG `frame-07.png`, `frame-30-on.png`, `frame-30-off.png`, `frame-64.png`. 구현은 `recipe-film-audio.ts`, `recipe-film-visual.ts`, `recipe-film.ts`, `tools/recipe-film-kit.py`를 확인했다.

### 음원과 구조

- 실제 PCM 길이 89.43327083333334초, 레시피 대비 −0.0000024066초로 샘플 반올림 범위다. peak 0.1429443, RMS 0.0191215, 클리핑 샘플 0개다.
- kick/snare/hat/rim WAV 네 파일의 SHA-256이 manifest와 모두 일치한다. 생성기는 seed를 고정한 잡음·오실레이터로 원샷을 만들며 외부 녹음을 읽지 않는다. 실제 믹서는 해당 저장 WAV를 읽어 이벤트 위치에 합산한다.
- 실제 이벤트 기록 414개: kick 115, snare 94, hat 158, rim 47. 6종의 킥 위치 구조, 5개 ratchet 패턴과 opening/broken/variation/space/return/outro 구간이 있다. 구간별 드럼 이벤트 수는 각각 10/112/97/26/140/29로 밀도 대비와 여백이 설계되어 있다.
- Strudel pad와 Strudel mini-notation에서 질의한 드럼 시점을 실제 샘플 믹싱에 사용한다. 레시피의 Sardine/Hydra 등의 선택은 계획이며 이 작품이 해당 엔진으로 실행됐다고 주장하지 않는다.
- low/high/onset은 최종 PCM에서 계산한다. 95백분위는 low 0.4006, high 0.0938, onset 0.7956이다. 직접 청취를 수행한 것은 아니므로 음색 만족도나 '들어 보니 좋다'는 판정을 하지 않았다.

### Three.js와 시각

- Scene, WebGLRenderer, RawShaderMaterial, WebGLRenderTarget이 실제 렌더 경로에 사용된다. PerspectiveCamera의 world 행렬이 광선 원점/방향에, view-projection 행렬이 광선 충돌 위치의 깊이 기록에 쓰인다. 단순 명목상 import가 아니다. Mandelbulb 구면 거듭제곱·거리 추정·레이마칭과 표면 법선을 확인했다.
- 실제 PNG에서 세부 입체 구조와 가림·회전이 보인다. 반면 색은 거의 teal/blue 두 계열에 머문다. 깊이·음악에 반응하는 색 다양성이라는 새 목표에는 부족하다.
- 같은 30초 위치에서 반응 on/off PNG를 디코드해 비교했다. 평균 RGB 절대 차이는 **0.2963/255**, 최대 차이는 **3/255**다. 수정 전 코드는 high에 0.045를 곱하고 onset도 작은 specular 가산으로만 써서, 기능은 연결됐지만 지각상 변화가 약하다.
- 필수 수정 지시: 깊이/trap에 따른 따뜻한 색·보라 영역을 실제 보이게 추가하고, high/onset을 상한 있는 지각적 범위로 매핑해 국소 색·가장자리 변화를 만든다. 전역 점멸이나 카메라 점프로 대체하지 않으며 표면 세부는 유지한다. 음원·카메라·기하 전체 재작성은 요구하지 않는다.

## 다음 판정에 필요한 증거

시각 담당에게 위 결함을 직접 전달했고 총괄이 수정 후 동일 시간의 반응 on/off와 다른 시간 프레임을 제공하기로 했다. 그 뒤 실제 저장된 전체 고정 프레임 파일과 원본 WAV 결합 결과에서 프레임 수·타임스탬프·길이·음영상 일치를 확인한다. UI의 '2683프레임 완료' 메시지만으로 실제 파일 생성이나 최종 영상 검증을 대신하지 않는다.

## 2차 색·반응 수정 검수

**색·반응 수정 통과. 최종 전체 렌더를 진행할 수 있다.** `runs/recipe-film-v02/`에서 동일 정지 시간의 30초, 72.54초(high 피크), 8.4초(onset 피크) on/off 총 6장을 직접 보았다. 이번 검수는 색 변경 범위만 확인했다.

- 청록·파랑에 국한됐던 표면에 보라 영역과 따뜻한 앰버 영역이 생겼다. 아래/측면의 따뜻한 색, 파란 홈, 보라 돌출부가 공간적으로 분리된다.
- 72.54초 반응 on에서는 보라 영역이 명확히 마젠타 쪽으로 강화되며, off의 푸른 보라와 구별된다. 8.4초 반응 on에서는 따뜻한 부분이 강화된다. 전체 화면에 똑같은 색을 덧씌우는 방식이 아니며 검은 배경·음영 구조를 유지한다.
- 표면의 가는 능선과 입체 가림이 유지되고 흰색으로 날아가는 하이라이트나 카메라 점프는 보이지 않는다. 새 필수 미술 수정은 없다.
- 소스에서 실제 측정 high/0.10, onset/0.80을 각각 clamp한 뒤 레시피 반응값과 공간 zone에 적용한다. Three.js 장면·카메라·기하는 그대로다.

세 이미지쌍의 독립 픽셀 분석 및 최종 준비 WAV의 이전 승인 WAV 비교는 `runs/recipe-film-v02/critic-color-analysis.json`에 기록한다. 최종 영상 파일의 검수 전까지 전체 작품 완료 판정은 유보한다.
