# 레시피 기반 색채 맨델벌브 영상

> 현재 제작 방향 변경: 2026-11-03 사용자는 최소 선 기하학, Seed of Life → Flower of Life, 교차 순간의 장작 소리를 요청했다. 아래 맨델벌브·드럼 내용은 이전 실험의 기록이며 현재 결과물의 설명이 아니다. 현재 제작 상태는 [flower-film-state.md](flower-film-state.md)를 확인한다.

2026-11-03 사용자 요청: `ambient-lab-recipe (3).json`으로 실제 영상을 출력한다. 프랙탈 색채는 오브제 깊이와 음악에 반응하고, Aphex Twin을 연상시키는 불규칙한 비트와 드럼 킷 샘플링을 추가한다.

## 제작 계약

- 원본 보존: `runs/recipe-film-v01/source-recipe.json`.
- 길이 89.4332732399575초, 템포 73.2085240142375 BPM, mysterious/D3, 여백 약0.8972. 느린 기본 박 위에 두 배 속도 세분 리듬을 추가한다.
- 맨델벌브 깊이1, 밀도약0.9296, 번짐약0.8880, 연결1, 관찰크기약0.7773, 움직임약0.6222, 소리반응약0.8061을 출발값으로 사용한다. 출력 품질을 위해 바꾼 해석은 기록한다.
- 직접 만든 드럼 원샷을 샘플로 사용하는 독창적 편곡. 특정 곡이나 상용 녹음을 추출하지 않는다.
- 색의 공간 분포는 실제 거리/표면/프랙탈 구조에서, 시간 반응은 최종 음원의 측정 특징에서 만든다. 단순 시간 기반 색 순환을 오디오 반응이라고 표현하지 않는다.
- 실제 실행: Strudel 기반 음악과 WebGL. 레시피의 Sardine/Hydra/Verovio/OpenCV 선택은 연결 계획이며 해당 도구가 실행됐다고 주장하지 않는다.
- 추가 사용자 지시: Three.js를 장면·카메라·렌더러 계층에 실제 사용한다. 프랙탈은 사용자 정의 셰이더로 유지하며 다른 3D 오브제 확장 경계를 둔다. 의존성은 pnpm CLI로 관리한다.
- 출력 우선 경로: WebCodecs에서 각 프레임을 `t=frame/30`에 계산하여 IVF로 저장하고 원본 WAV와 FFmpeg로 결합한다. 미지원이면 실시간 WebM 대체 경로를 사용하고 실제 결과를 명시한다.

## 책임과 검수

- Terra6.1 `native_sample`: 별도 오디오 모듈, 샘플 킷·비트·음원 특징·출처. 기존 엔진 보존.
- Terra6.1 `comparison_preview`: 별도 제작 페이지, 맨델벌브 색채·프레이밍·동기 녹화.
- Astra `workbench_critic`: 실제 출력물 검수와 수정 필요 항목. 청취되지 않은 음질을 청취 완료로 보고하지 않는다.
- 총괄: CUA 실제 UI 조작, 파일 수집·전달, FFmpeg 변환, 사용자 인계. 무거운 출력은 한 번에 하나.

완료에는 실제 재생 가능한 음악 포함 영상, 약89.43초 길이, 드럼 샘플 출처와 변화하는 리듬, 공간에 따라 구분되는 색채, 실제 음악 반응, 재생·출력 동기 증거가 필요하다. 프레임 간격과 해상도는 측정값대로 보고한다. 기존 검수의 03:56 KST 상한을 유지하며 통과하거나 한계가 확인되면 구체적인 상태를 남긴다.

## 상태

1차 실제 출력 검수: 오디오·샘플 출처 통과. 실제 WAV 89.433270833초, peak 0.14294, 클리핑 없음. 원샷 4개 해시 확인, 드럼 이벤트 414개와 6개 섹션의 변화가 기록됐다. Three.js 카메라·장면·렌더 타깃도 실제 사용한다.

시각은 수정 중: 7·30·64초 PNG가 청록/파랑에 편중되고 30초 음악 반응 on/off의 평균 차이가 0.296/255로 약했다. Astra 지적에 따라 깊이/프랙탈 구조에 따른 보라·따뜻한 색 영역과 음악 특징의 가시적 가중치를 보완한다.

출력은 개발용 HMR의 재초기화를 피하기 위해 Nx `studio:preview --port=4300`의 고정 빌드에서 수행한다. 첫 1080p 출력 UI는 2683프레임 완료를 표시했지만 실제 다운로드 파일을 확보하지 못했으므로 검증된 영상으로 세지 않는다. 수정본은 다운로드 이벤트부터 등록해 파일을 확보하고 검사한다.

기존 작업실·다른 프로젝트·기존 출력은 덮어쓰지 않는다. 음악과 시각을 같은 PCM 타임라인으로 통합하고 실제 파일 기준으로 최종 판정한다.

## 수정본 출력

- Astra의 색채 수정 검수 통과: 30초 평균 차이4.11/255, 72.54초6.71/255, 8.4초3.95/255. 보라·파랑의 깊은 영역과 호박색 면이 구분되고, 국소 반응에서도 형태와 세부가 유지된다.
- 실제 다운로드한 IVF: `runs/recipe-film-v02/film-silent.ivf`, VP9 1920×1080, 시간 단위1/30초, 디코드2683프레임, 길이89.433333초.
- 정확히 같은 생성물의 `music-render.wav`와 FFmpeg로 결합한 H.264/AAC 최종 MP4: `runs/recipe-film-v02/dp-sts-chromatic-mandelbulb-final.mp4`.
- 원본 킷: `runs/recipe-film-v02/dp-sts-original-drum-kit.zip`. 원본 레시피·분석·A/B PNG도 같은 디렉터리에 보관한다.
- 제작 화면: `http://localhost:4300/recipe-film.html`. MP4 미리보기: `http://localhost:4300/dp-sts-chromatic-mandelbulb-final.mp4`. 4300은 Nx preview 프로세스가 켜져 있을 때 사용 가능하며, 영구 출력은 runs 아래 파일이다.
- 최초 결합본은 `-shortest` 때문에 마지막 프레임이 누락되어 2682프레임이었다. 같은 IVF·WAV를 이 옵션 없이 결합한 교정본은 ffprobe에서 2683프레임, 영상89.433333초, 음성89.433271초, 두 스트림 시작0초를 확인했다. 이전 결합본을 최종 전달용으로 사용하지 않는다.
- CUA 실제 MP4 재생과 1080p metadata/error null을 확인했다. 총괄은 교정본의 89.4초 마지막 프레임을 FFmpeg로 실제 추출했다(`final-tail-root.png`, exit 0). 색채·음악 반응은 Astra 승인 범위이며, 교정본 끝 프레임의 독립 최종 기록은 검수 문서에서 확인한다.

## 전달 상태

최종 MP4·WAV·드럼 킷을 전달한다. Astra의 시각 색채·음악 반응 승인 이후 최종 mux에서 누락된 끝 프레임을 교정했고, 총괄이 2683프레임·89.433333초와 마지막 89.4초 프레임 추출 성공을 검증했다. Astra의 교정본 최종 기록은 완료되지 않아 전체 독립 검수 완료로 표현하지 않는다. 03:56 KST 검수 상한이 지난 것을 확인해 추가 에이전트 검수는 중단했다.
