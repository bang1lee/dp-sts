# 시각 연출 조작 아티팩트 독립 검수

판정: **수용. 차단 결함 없음.** Astra `workbench_critic`가 새 연출 조작 범위만 검수했다. 기존 작품의 음악·완성 영상 판정은 유지하며, 이번 작업에서 89초 전체 영상을 다시 렌더하지 않았다.

## 직접 확인한 구현

- `recipe-film-direction.ts`의 절대 시간 평가 함수를 미리보기·정지 이미지·고정 프레임 출력이 함께 사용한다. 기본값은 기존 차수·카메라 전개·FOV·색·음악 반응을 유지한다. 기본 카메라와 형태의 이전 계산 일치, 고정 시간의 결정성은 순수 테스트에 포함된다.
- 형태 차수·회전·변형·세로 늘이기는 실제 거리 추정 함수에 적용된다. 세로 스케일에 맞춰 거리 추정과 탐색 경계를 보정한다. 카메라 위치·시선·FOV는 Three 카메라와 레이 방향에 적용된다. 이름만 존재하는 조절기는 발견하지 않았다.
- 방향 문서는 버전·종류·필드 목록·유한 수치·범위·카메라 경로·출력 크기와 30fps를 검사한다. 레시피/킷 SHA 및 음악 값이 현재 작품과 일치해야 하며 검증이 끝난 뒤에만 UI·렌더 값을 바꾼다. 알 수 없는 필드와 다른 음악을 조용히 수용하지 않는다.
- 방향·출력 크기·음악 준비가 바뀌면 이전 IVF 재다운로드 캐시를 비운다. 출력 시작 시 방향 값을 복사해 고정하고, 슬라이더·프리셋·JSON 적용/불러오기를 잠근다. 취소 후 조절 상태와 재생 위치를 복구한다.
- 음원 모듈·샘플 킷을 바꾸는 새 경로는 없다. 출력에서는 같은 음원 특징을 같은 시간 인덱스로 읽는다. 새 조합의 완성 영상은 사용자가 정한 방향 JSON으로 후속 렌더할 수 있다.

## 실제 이미지·문서 검사

입력은 `runs/visual-direction-v01/`의 `original-30.png`, `arc-power6-30.png`, `roundtrip-30.png`, `near-surface-40.png`, `direction.json`, `browser-evidence.json`이다. 네 이미지를 직접 열어 보았다.

- 기본 화면에서 기존 보라·파랑·따뜻한 색의 Mandelbulb를 확인했다. 차수 6과 올라가는 호 경로를 적용하면 큰 표면 무늬와 시점이 실제로 달라진다.
- 변경 설정을 저장하고 초기화한 뒤 불러온 화면은 변경 전 화면과 SHA-256까지 동일하다: `143e64bb226cff81c8ded12fced43c1f5a2748dac1526fee9069e0e2bc6e2dd2`. 저장 문서에도 차수 6, stretch 1.15, arc, cameraSpeed 0.75, cameraHeight −0.15 등의 실제 값이 들어 있다.
- 표면 가까이 프리셋의 40초 화면은 세부 표면을 보여 준다. 검은 화면이나 의도치 않게 물체 내부에 들어간 결과가 아니다.

## 총괄의 실제 브라우저 관찰

브라우저는 총괄이 전담했다. 잘못된 JSON은 기존 차수 6을 유지하며 거부했고, 실제 파일 선택기로 저장 JSON을 불러와 복원했다. 출력 중 프리셋·JSON·슬라이더 잠금과 취소 후 복구를 확인했다. 무음 재생은 끝까지 진행했고, 390px 화면에서 가로 넘침이 없었다. 최종 콘솔 오류는 없었다.

새로 준비해 다운로드한 WAV의 SHA-256은 기존 승인 음원과 동일한 `b5749807a35064fcb2d47999075310e29437604c0346f91faccf6c6a0f3ebb3c`로 보고·기록됐다. 음악을 유지하면서 연출만 바꾸는 사용 흐름을 뒷받침한다. 담당자 보고에 따르면 방향 테스트 5건, typecheck, build가 통과했으며 Expect는 기존 인증 문제로 차단됐다. 차단된 검사를 통과로 표기하지 않는다.

## 수용 범위

사용자가 직접 형태·시간 변화·카메라·색을 탐색하고, 음악 신원을 고정한 방향 JSON을 저장해 총괄에게 전달할 수 있는 아티팩트로 수용한다. 검증한 기본값·프리셋·왕복 조합을 넘어 모든 극단값 조합의 미감을 보장하지 않는다. 사용자가 고른 새 연출의 최종 전체 영상 검수는 후속 렌더의 범위다. 이번 도구 전달을 위해 추가 전체 렌더나 미술 변경은 필요하지 않다.
