# 맨델벌브 시각 연출 도구

## 현재 요청

기존 dp-sts 음악과 맨델벌브 렌더링 방식을 유지한다. 사용자가 아티팩트에서 형상·카메라 이동·오브제 변화를 조절하고, 저장한 값을 전달하면 같은 설정으로 영상을 출력할 수 있게 한다.

## 작업 범위와 담당

- Terra `comparison_preview`: 기존 recipe-film 화면, 시각 렌더러, 순수 설정 모듈과 검증 테스트.
- Astra `workbench_critic`: 음악 보존, 입력 검증, 재현 가능한 시간 계산, 조작 결과와 출력 경로의 독립 검수.
- 총괄: 실제 브라우저 조작·저장/불러오기 확인, 사용자 안내와 증거 정리.
- 다른 실험의 변경 사항을 보존한다. 음악 생성 모듈·드럼 킷은 수정하지 않는다.

## 완료 조건

1. 음악 준비 없이도 시각 설정과 무음 탐색을 확인할 수 있다.
2. 형상과 카메라 프리셋 및 수치 조절이 실제 화면에 반영된다.
3. 설정 JSON을 저장·불러와 같은 시점의 화면을 복원한다. 잘못된 입력과 다른 음악 설정은 기존 상태를 바꾸지 않고 거절한다.
4. 미리보기와 출력은 같은 시간 기반 계산을 사용한다. 출력 중에는 설정 변경을 막고, 변경 후에는 이전 영상 다운로드를 무효화한다.
5. 사용자에게 전달할 프롬프트와 사용 안내가 있다.

## 상태

구현·실제 브라우저 기능 확인·Astra의 이번 도구 범위 검수 통과. Astra가 직접 PNG 4장과 설정/렌더 연결 소스를 확인했고 추가 필수 수정은 없다고 판정했다. 기존 89.43초 작품의 완료 검수와 새 연출 도구의 검수는 구분한다. 새 요청은 도구 제작이며 새로운 전체 길이 작품을 자동 렌더하거나 원격 저장소에 게시하지 않는다.

## 실행 증거

- Terra: `studio:direction-test` 5건, `studio:typecheck`, `studio:build` 통과. expect 자동 검사는 Claude 인증 누락으로 실행 전 차단됐으며 통과로 간주하지 않는다.
- 총괄 CUA: 30초 원본 → 올라가는 호·차수 6 조절 → JSON 다운로드 → 원본 초기화 → JSON 적용 → 실제 파일 선택기로 다시 불러오기 확인.
- `arc-power6-30.png`와 `roundtrip-30.png` SHA-256이 `143e64bb226cff81c8ded12fced43c1f5a2748dac1526fee9069e0e2bc6e2dd2`로 동일했다. 잘못된 JSON은 상태를 유지한 채 거부했다.
- 새로 준비해 다운로드한 WAV의 SHA-256은 `b5749807a35064fcb2d47999075310e29437604c0346f91faccf6c6a0f3ebb3c`로 기존 `music-render.wav`와 동일하다. 음악 생성 모듈·오디오 패키지·킷의 Git 변경 없음.
- 근접 프리셋의 40초 장면에서 실제 표면이 보였다. 무음 재생·시간 탐색·오디오 재생 시작을 확인했다. 직접 청취 평가를 수행했다는 의미는 아니다.
- 고정 프레임 출력을 시작하면 프리셋·JSON 적용·형상 슬라이더가 비활성화되고, 취소하면 복원됨을 확인했다. 새 방향으로 전체 영상 인코딩을 끝까지 수행하지는 않았다.
- 390px 반응형 확인에서 문서 폭이 뷰포트를 넘지 않았다. 브라우저 콘솔 오류 없음. 최종 전달은 다른 개발 변경의 HMR 영향을 피하는 `http://localhost:4300/recipe-film.html`이다.
- 증거: `runs/visual-direction-v01/`의 JSON·PNG·browser-evidence.json. 사용법과 출력 요청문은 `docs/visual-direction-guide.md`.
