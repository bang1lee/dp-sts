# Flower of Life — 실제 출력 상태

2026-11-03. 사용자의 최소 연산·최소 선 디렉션을 따라 별도 제작 페이지와 출력물을 만들었다. 이전 실험 소스는 보존했다. 길이는 직전 레시피의 89.433273초를 유지했다.

## 결과물

- 최종 파일: `runs/flower-film-v01/flower-of-life-complete.mp4`.
- 실제 영상: H.264, 960×540, 30fps, 2,683프레임, 89.433333초.
- 실제 오디오: AAC, 스테레오 48kHz, 89.433271초. 원본은 같은 폴더의 `flower-fire.wav`.
- 브라우저 원본: `flower-silent.ivf`. 실제 UI 다운로드에서 확보했다.
- 실시간 페이지: `http://localhost:4200/flower-film.html`. 소리 준비, 재생·정지·탐색, PNG/WAV/사건표/영상 출력 제공.
- `flower-poster.png`는 최종 MP4의 82초 프레임이다.

첫 MP4인 `flower-of-life.mp4`는 FFmpeg `-shortest`로 마지막 한 프레임이 빠졌다. 검수에서 발견해 해당 옵션 없이 다시 결합했다. 최종 파일은 이름에 `complete`가 있는 파일이다.

## 구현과 범위

동일 반지름의 원을 삼각 격자에 배치한다. 1개 → 7개 → 19개 순서로 드러나며, π는 원호와 60도 간격의 계산에 사용한다. π의 숫자열에서 꽃이 생성된다는 주장은 하지 않는다. 수식과 조사 출처는 [연구 노트](../flower-geometry-research.md)에 있다.

Three.js에서 미리 계산한 3,648개 선분을 공유한다. 세 잔향은 0.18·0.36·0.65초 전의 선 생성 상태를 재현한다. 긴 프레임 이력, 광선 진행 프랙탈, 그림자, 블룸은 사용하지 않는다. 렌더링은 최대 9 draw call로 제한하며 정지 상태에서는 WebGL 다시 그리기를 건너뛴다. RAF 콜백 자체는 계속 예약되므로 CPU 사용이 0이라고 주장하지 않는다.

교차점에 도착하는 기하학적 사건 77개를 같은 오디오 시간표에 배치했다. 72개 서로 다른 원 쌍의 교차 지점 발생 144건을 포함하며, 같은 시각·위치의 다중 교차는 하나의 사건음으로 합친다. 이미 겹친 원이 매 프레임 소리를 다시 내지는 않는다.

장작 소리는 직접 합성한 6종 원샷이며 현장 녹음이 아니다. 샘플과 출처·해시는 `assets/fire-kit/`에 있다. 이번 버전에는 배경 음악이나 이전 드럼 편곡을 넣지 않았다.

## 검수 증거

- Terra6.1: 시각·오디오 구현. Astra: 독립 검수.
- 실제 UI의 WAV는 검증용 WAV와 바이트 단위로 같다. 사건표의 77개 오디오 시작 샘플과 교차 쌍이 일치한다. 미세한 부동소수점 차이는 별도 기록했다.
- 원본 PCM의 peak는 약 −17.97dBFS이며 클리핑이 없다. 이는 청취에 의한 미감 판정과 구분한다.
- Nx studio 타입 검사와 최종 빌드 통과. 실제 UI 재생·정지·끝으로 탐색과 파일 다운로드 확인.
- `expect` 검수는 실행하지 않았다. 해당 항목을 통과로 표시하지 않는다.
- 최종 인코딩 파일의 독립 검수 판정과 세부 증거는 [flower-critique.md](flower-critique.md)를 따른다.
- Astra 최종 파일 검수 통과: 2,683프레임과 양 스트림의 0초 시작을 확인했다. 77개 교차 영역 모두 사건 직후 불씨 표시가 나타났고, 네 오디오 사건 구간의 AAC/WAV 상관은 0샘플 지연에서 최대였다. 전체 파형 상관은 0.999762였다. 압축 뒤 잔향은 매우 절제되어 보인다. 청취에 의한 장작 음색의 사실성·선호도는 평가하지 않았다.
