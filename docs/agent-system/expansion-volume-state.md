# 같은 작품 안에서 이어지는 입체 확장

2026-11-03 사용자 정정: “라인의 형상이 주된 표현이지만 맨델벌브의 입체감도 표현된 5초짜리”는 직전 작업에서 연장·확장하라는 뜻이다. 별도의 만델벌브 연구 영상으로 분리한 이전 해석을 수정한다.

## 유지하는 작품의 정체성

Expansion의 원 43개, 1→6→36 재귀, 장작에서 만든 앰비언스, 109.812786 BPM, 같은 카메라와 잔상을 유지한다. 맨델벌브는 다른 장면으로 대체하는 것이 아니라 이 원 구조 안에 입체적 굴곡과 깊이를 더한다.

현재 구현 범위는 같은 작품의 20~25초 구간이다. 기존 전체 30초 장면의 그 구간에 실제 power-8 맨델벌브 자산의 단면선·깊이 표면을 통합하고, `expansion-film.html?excerpt=volume`에서 동일한 시간축의 5초를 보여준다. 오디오는 새로 편곡하지 않고 기존 PCM의 해당 구간을 사용한다.

원의 위상·카메라·음악을 다른 초기 상태로 재시작하지 않는다. 새 영상 파일로 저장하는 것은 검토용 버전 보존이며 별개 작품으로 분리한다는 뜻이 아니다. 원이 실제로 다른 곡선으로 변형되는 구현이 아니라면 “원 자체가 맨델벌브로 수학적으로 변형된다”고 설명하지 않는다.

## 상태

Terra6.1이 기존 페이지와 렌더러를 수정했다. Nx 타입 검사와 빌드가 통과했다. 별도 원형 실험 페이지를 추가하지 않고 기존 Expansion 페이지의 전체 시간축과 5초 발췌 모드를 연결했다.

실제 브라우저에서 받은 파일을 `runs/expansion-volume-v01/`에 보존했다. `expansion-volume-5s.mp4`는 H.264 960×540·30fps·150프레임이며 영상과 AAC 모두 정확히 5초다. 원본은 같은 폴더의 WAV·IVF·manifest다. `poster.png`는 완성 MP4의 4.5초 프레임이다. 실제 재생, 탐색과 다운로드를 확인했다.

전체 30초를 새 영상으로 재출력한 것은 아니다. 기존 전체 재생 페이지에는 통합 시각이 반영되었고 이번 전달 파일은 그중 20~25초만 출력한 검토본이다. 앞선 파일들은 덮어쓰지 않았다. 독립 검수 기록: [expansion-volume-critique.md](expansion-volume-critique.md).

Astra 최종 검수 통과: 150프레임 전체에서 가장자리 잘림이 없고 최소 밝은 형상 여백은 56px였다. UI WAV는 원본 PCM의 960000~1199999번 샘플(20~25초)과 정확히 같다. AAC와 WAV의 세 구간 상관에서 지연은 0샘플이었다. 기존 영상의 600번 프레임과 새 영상의 첫 프레임은 같은 원 배치·카메라를 보이며, 뒤로 갈수록 중앙 원과 주변 재귀 구조를 유지한 채 맨델벌브 단면이 나타나는 것을 실제 프레임으로 확인했다. 이는 같은 작품의 추가적 입체 확장이고 원 자체의 수학적 모핑이라고 주장하지 않는다.
