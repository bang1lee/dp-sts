# Expansion — 연결을 기다리는 표류

2026-11-03 사용자 디렉션: 미니멀하게 시작해 3D 오브제로 보이고, 오브제가 입자로 인지되며 공간 속에서 연결을 기다리는 표류 상태로 이어간다.

## 이번 전개

같은 작품의 새 30초 전개를 `expansion-film.html?chapter=drift`에서 다룬다. 기존 원과 따뜻한 선, 검은 여백, power-8 맨델벌브, 장작에서 얻은 앰비언스와 109.812786 BPM을 이어간다. 기존 전체·5초 발췌 모드와 출력은 보존한다.

연출 해석: 초반의 가는 원이 입체의 윤곽을 드러낸다. 입체를 구성하던 위치에서 입자가 인식되기 시작하고, 마지막에는 형태의 기억을 느슨하게 유지하며 움직인다. 폭발이나 빠른 산개로 처리하지 않는다. 일부 입자 사이의 선은 짧게 나타나되 틈을 남겨 연결의 가능성과 기다림을 표현한다. 완성된 네트워크를 결말로 삼지 않는다.

시간 배분의 출발점은 선 0~7초, 입체 7~15초, 입자로 인식되는 전환 15~23초, 표류와 연결의 기미 23~30초다. 화면 검수에 따라 작은 조정은 허용한다. 음악은 기존 30초 PCM을 사용한다.

## 계산과 검수

입자는 기존 맨델벌브 형상의 표면·단면에서 가져오고 제한된 수만 사용한다. 표류는 시간으로부터 계산하며, 매 프레임 모든 입자 쌍을 비교하거나 잔상 프레임을 무한히 누적하지 않는다. 실제 개수·연결 수·출력 프레임은 구현 후 기록한다.

Terra6.1이 코드, Astra가 독립 검수를 담당한다. 총괄은 실제 UI 재생·다운로드·음원 결합과 인계를 맡는다. 완료 기준은 실제 30초·900프레임 영상, 같은 물체의 연속된 인식 변화, 입체감, 느린 표류와 미완의 연결, 화면 잘림 없는 구도와 음악의 시간축이다.

## 구현과 스틸 검수

표류 장은 기존 페이지의 `?chapter=drift`로 구현했다. 총 1,400개의 입자는 기존 power-8 표면의 위치 중 중복을 줄여 선택한 점이다. 0.22초 지연 잔상 한 겹과 연결 후보 12쌍을 사용한다. 연결은 두 조각 사이에 틈을 남기며 완성된 네트워크로 전환하지 않는다. 최대 draw call은 7이며 무한 누적 프레임 버퍼를 만들지 않는다.

실제 UI에서 3·12·27초 PNG, 음원과 manifest를 저장했다. 독립 검수는 시작 선, 입체, 입자 사이의 형태 기억과 여백을 확인했다. 초기 입자의 사각형 모서리가 거칠게 보여, 같은 입자 수를 유지하면서 공유 원형 알파 텍스처와 메인 2.3px·잔상 2px 점으로 수정했다. 타입 검사와 Nx 빌드 통과.

원본 음원은 새 편곡 없이 기존 30초 앰비언스를 사용한다. 실제 UI 재생과 30초 끝에서 정지하는 동작을 확인했다. 검수 기록은 [expansion-drift-critique.md](expansion-drift-critique.md)에 둔다.

## 실제 파일

`runs/expansion-drift-v01/expansion-drift-30s.mp4`는 실제 브라우저 다운로드 IVF와 WAV를 FFmpeg로 결합한 파일이다. ffprobe에서 H.264 960×540, 30fps, 900프레임과 영상·AAC 모두 정확히 30초임을 확인했다. 원본 음원과 IVF, 수정 후 `manifest-final.json`을 같은 폴더에 보존했다. `poster.png`는 27초 프레임, `progression.png`는 3·12·27초 실제 프레임을 나란히 놓은 이미지다.

첫 파일의 컨테이너·음원·화면 경계 검사는 통과했으나, 685→686 프레임(약 22.867초)에서 뒤쪽 입자가 갑자기 나타났다. 반투명 표면이 깊이 버퍼를 쓰다가 사라지는 순간 입자가 한꺼번에 드러나는 문제였다. 입자와 지연 입자의 깊이 테스트를 꺼 점의 기존 점진적 페이드가 그대로 보이게 수정했고, 단면선의 깊이 테스트는 유지했다. 타입 검사·빌드 재통과 후 재출력한다. 첫 파일은 결함 증거로 남긴다.

주관적인 청취를 수행했다고 주장하지 않는다.

수정 출력: `runs/expansion-drift-v01/expansion-drift-30s-complete.mp4`. 브라우저 원본은 `drift-fixed-silent.ivf`이며, 음원은 첫 버전과 동일 WAV다. 최종 전개 이미지는 `progression-final.png`에 3·12·27초 실제 프레임으로 남겼다. 화면의 점들이 다른 장면에서 교체되는 방식이 아니라 동일 표면 좌표에서 점차 드러나고 천천히 이동하는 방식이다.

**Astra 최종 검수 통과.** 실제 685→686 프레임의 입자 급증이 해소되었다. 평균 픽셀 변화는 0.75338에서 0.07217로 줄어 주변 프레임의 0.068~0.084 범위와 이어진다. 전체 900프레임에서 화면 가장자리 접촉이 없고 최소 밝은 형상 여백은 119px였다. 영상·오디오 모두 시작 0초·길이 30초다. 디코딩 오디오 해시가 검증된 기존 앰비언스와 같으므로 이전 55개 박의 0샘플 지연 검사도 유지된다. 이 판정은 기술·시각적 연속성의 검수이며 사용자 미감 승인과 구분한다.
