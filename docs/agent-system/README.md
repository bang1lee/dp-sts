## 역할과 실제 적용

복잡한 구현은 **GPT-6.1 Terra / ultra**에 맡긴다. 현재 협업 도구가 제공하는 가장 높은 추론 설정이다. 총괄은 현재 세션 모델을 유지하며 미술 방향, 사용자 의견, 통합과 렌더 순서를 맡는다. 비평 담당은 구현 담당과 독립적으로 실제 산출물을 보고 판단한다.

추가 결정: **GPT-6 Astra**가 복잡도가 시각적 풍부함으로 작용하는지, 형태가 무너지는 지점을 실제 샘플로 조율한다. 계산과 복잡한 구현은 Terra가 수행한다. 반복 맥락 전달을 줄인 여력은 구조·레이어·상호작용의 심화에 사용한다. 절감 토큰을 계측하거나 복잡도와 정량적으로 환산한 것은 아니다.

두 Terra 작업은 전체 대화를 상속하지 않는 `fork_turns: none`으로 실행 요청하고 도구에서 생성 성공을 확인했다. 모델 내부 처리량이나 실제 토큰 절감률은 계측하지 않았다. 모델명을 파일에 기록한 것과 실제 에이전트를 실행한 것을 구분한다.

## 토큰을 줄이는 지점

- 긴 대화를 매번 복제하지 않고 목표, 제약, 파일 소유권, 인터페이스, 증거만 전달한다.
- 작업별 소유 파일을 분리해 같은 코드를 여러 에이전트가 반복 수정하지 않는다.
- 후속 수정은 기존 담당에게 차이와 실패 근거만 전달한다.
- 렌더링과 파일 검사는 로컬 도구가 수행하고, 에이전트는 짧은 결과와 필요한 표본을 읽는다.
- 예술적 복잡도, 영상 길이, 해상도, 독립 검수는 토큰 절감의 대상으로 삼지 않는다.

## 실행 경계

[model-routing.json](model-routing.json)은 총괄이 협업 도구 호출에 적용하는 프로젝트 로컬 계약이다. 별도의 자동 모델 라우터나 과금 차단 장치가 아니다. 최대 2개의 Terra 구현 작업을 독립된 파일 범위에서 진행하고 무거운 렌더는 한 번에 하나만 실행한다. 전역 모델 설정과 다른 프로젝트의 하네스는 변경하지 않는다.

구현 완료, 실제 렌더 완료, 기술 검증 통과, 표본 시각 검토, 직접 청취는 각각 별도로 기록한다. 한 항목의 통과를 다른 항목의 통과로 확대하지 않는다.

## 사용자에게 보이는 검수

이미지 검수의 근거를 숨기지 않는다. 실제 검수 이미지 또는 비교 보드, 관찰한 문제, 미학적 판단, 수정 지시, 수정 결과를 대화에서 함께 보여준다. 에이전트 수용은 사용자 컨펌과 다르다. 과거 검수를 새로 투입한 Astra의 검수로 소급해 부르지 않는다.
