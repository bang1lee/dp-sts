# 확장하는 원의 균형 — 장작에서 앰비언스로

2026-11-03 사용자 디렉션: 원의 균형이 더 크게 반복 확장되는 과정에서 비트를 느낀다. 장작 소리는 일정한 리듬에 1.5배 속도로 놓고, 그 음으로부터 앰비언스 음악을 만든다. 선은 입체적이고 구체적으로, 잔상과 프랙탈 구조를 연결한다. Aphex Twin은 공간적·실험적 질감의 참고이며 특정 곡을 재현하거나 녹음을 가져오지 않는다.

## 이번 샘플의 결정

- 길이 30초. 사용자가 새 길이를 지정하지 않아 확장 전개를 볼 수 있는 샘플 길이로 선택하고 대화에 알렸다.
- 기준 속도는 보존된 `runs/recipe-film-v01/source-recipe.json`의 73.2085240142375 BPM. 기존 교차 소리의 간격은 불규칙하므로 일정한 리듬의 속도 기준으로 직접 쓸 수 없다.
- 적용 속도는 정확히 1.5배인 109.81278602135625 BPM. 기본 장작 박의 간격은 `60 / BPM`초이며 박 위치의 불규칙성은 넣지 않는다.
- 직접 합성한 fire-kit 파형을 공진·늘어지는 잔향·조각 재배치의 재료로 사용한다. 기존 장작 소리와 음악 층 사이의 출처를 기록한다.
- 입체 원의 군집과 제한된 반복 단계, 실제 시간 지연을 갖는 잔상, 동일 PCM의 분석 특징과 박 시간표를 연결한다. 카메라의 후퇴와 새 군집의 드러남이 확장 감각을 만든다.
- Three.js 지오메트리 공유와 제한된 반복 수로 비용을 관리한다. 무한 프랙탈 또는 모든 장치에서 최소 연산이라고 주장하지 않는다.

## 책임과 완료 조건

Terra6.1 오디오: `expansion-audio.ts`. Terra6.1 시각·화면: `expansion-film`과 `expansion-visual`. Astra는 실제 파일과 시각·음원 데이터를 독립 검수한다. 총괄은 실제 UI 실행, 다운로드, FFmpeg 결합과 인계를 맡는다. 이전 출력물은 보존한다.

완료 조건은 30초 / 30fps / 900프레임 영상에 실제 음악을 결합하고, 규칙적인 박·음원 유효성·시각의 확장과 입체감·동일 시간축을 확인하는 것이다. 청취 미실행은 청취 완료로 표시하지 않는다. `expect-cli`는 별도 브라우저 제어를 요구하므로 현재 CUA 전용 브라우저 제어 지침과 충돌한다. 대신 실제 CUA UI 동작과 파일 기준 검사를 수행하고, expect 통과로 표시하지 않는다.

## 실제 출력과 검수

- 첫 결합 파일: `runs/expansion-film-v01/expansion-30s.mp4`. 실제 브라우저에서 받은 IVF와 WAV를 FFmpeg로 결합했다. 아래 초반 프레이밍 결함 때문에 최종 전달본에서 제외한다.
- ffprobe 확인: H.264 960×540, 30fps, 900프레임. 영상·AAC 오디오 모두 정확히 30.000000초다.
- 원본 `expansion-film.wav`는 48kHz 스테레오이며 UI 다운로드와 단독 검증 음원이 바이트 단위로 같다. 55개 박이 약 0.546384462초 간격으로 놓인다. PCM peak 약 0.205677, 클리핑 없음.
- 재생 페이지: `http://localhost:4200/expansion-film.html`. 재생·끝에서 정지·탐색·실제 PNG/WAV/manifest/IVF 저장을 확인했다.
- 최종 타입 검사와 Nx studio 빌드 통과. 독립 검수 판정은 [expansion-critique.md](expansion-critique.md)에 기록한다.

## 시각 검수에 따른 변경

초기 45개 원의 세 겹 배치는 작은 화면에서 선이 끊겨 보이고 입체감이 약했다. `before-15.png`, `before-25.png`에 실제 UI 증거를 보존했다.

수정본은 부모마다 여섯 자식을 만드는 실제 두 단계 재귀다. 자식 반지름은 부모의 0.4배, x·y 평면의 중심 오프셋은 부모 반지름과 자식 반지름의 합이다. z는 별도로 배치하므로 이를 3차원 중심 거리라고 부르지 않는다. 총 1+6+36=43개이며 무한 반복을 계산하지 않는다.

선을 두껍게 하고 조명·비스듬한 시점·앞뒤 밝기를 적용했다. 한 겹의 0.22초 지연 상태가 잔상을 만든다. 마지막 카메라 거리를 11에서 8.2로 줄여 전개 후반에도 크기가 유지되도록 했다. 레벨별 관 지오메트리를 공유하고, 잔상 포함 최대 86개 인스턴스·6 draw call로 제한한다. 이는 소스의 상한이며 기기별 GPU 프레임 시간 측정값은 아니다.

`poster-24.png`는 첫 결합 MP4의 24초 프레임이다. 첫 세 겹 배치를 정확한 프랙탈로 설명하지 않으며, 최종본만 고정 비율의 부모·자식 재귀를 사용한다.

압축 영상의 전체 프레임 검사에서 5.87~8초 구간의 위쪽 원이 잘리는 것을 발견했다. 카메라가 2~10초 사이에 더 일찍 멀어지도록 수정하고 재출력한다. 시작 z=4.9와 끝 z=8.2는 유지한다. 구현자의 900프레임 투영 계산은 최소 상하 여백 약 55.4px였으며, 실제 인코딩 프레임에서 다시 확인한다. 첫 파일의 오디오·30초 길이·900프레임 및 55개 박의 AAC/WAV 지연 0샘플 검사는 통과했다.

수정 재출력 파일은 `runs/expansion-film-v01/expansion-30s-complete.mp4`이며, 브라우저 원본은 `expansion-fixed-silent.ivf`다. `poster-final.png`는 이 수정 파일의 24초 실제 프레임이다. 첫 결합 파일은 실패 증거로 보존하며 사용자에게는 수정 파일을 전달한다. 수정 뒤 Nx studio 빌드를 다시 통과했다.

수정 파일의 독립 검수도 완료했다. 전체 900프레임을 실제 디코딩해 밝은 내용의 최소 가장자리 여백 55px를 확인했고, 기존 잘림 구간의 프레임 200을 직접 확인해 해결됐음을 판정했다. 영상·음원 모두 정확히 30초이며 시작 시간은 0이다. 디코딩 음원은 앞서 검증한 파일과 바이트 단위로 같아 55개 박의 지연 0샘플 결과가 그대로 유효하다. 최종 근거는 `runs/expansion-film-v01/critic-corrected/`에 있고, 독립 검수는 통과 상태다.

**Astra 최종 검수 통과.** 수정 MP4의 전체 900프레임을 디코딩해 화면 가장자리 접촉이 없음을 확인했고, 밝은 형상 기준 최소 여백은 55px였다. 문제였던 200번 프레임과 초반·중간·마지막 실제 이미지를 확인했다. 양 스트림은 시작 0초·길이 30초이며, IVF도 연속된 900패킷이다. 디코딩한 오디오는 첫 파일과 해시가 같아 기존 55개 박의 지연 0샘플 검사 결과가 유지된다. 이는 기술·시각 검수이며 주관적 청취 승인과 구분한다.

직전 5초 `runs/line-bulb-v01/line-bulb-5s.mp4`도 실제 150프레임·5초·AAC 포함으로 저장하고 독립 검수했다. 현재 확장 샘플과 별도로 보존한다. 청취를 통한 주관적 음색 평가나 사용자 미감 승인을 완료했다고 주장하지 않는다.
