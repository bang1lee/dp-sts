# 선으로 읽는 맨델벌브 — 5초 변주

2026-11-03 요청: 선의 형상을 주된 표현으로 유지하면서 맨델벌브의 입체감을 표현하는 5초 샘플을 추가한다. 기존 Flower of Life와 다른 작품은 보존한다.

## 표현과 구현 기준

검은 여백 속 가는 선을 주역으로 삼는다. 앞뒤 가림, 깊이에 따른 밝기 차이, 느린 시점 변화가 입체의 굴곡을 드러내도록 한다. 선을 지나치게 촘촘히 쌓아 면처럼 보이게 만들지 않는다.

구면좌표에서 반지름을 8제곱하고 두 각도를 8배 하는 반복으로 power-8 Mandelbulb를 계산한다. 수학적 출처: [Daniel White의 Mandelbulb 설명](https://www.skytopia.com/project/fractal/mandelbulb.html). 유한한 해상도와 반복 횟수로 근사한 표면임을 명시한다. 단순 구를 변형해 맨델벌브라고 부르지 않는다.

형상 준비와 매 프레임 재생 비용을 구분한다. 형상은 준비 단계에서 계산하고, 재생에서는 Three.js의 정적인 선·표면과 카메라를 사용한다. 전체 기기에서 최소 연산이라는 보장은 하지 않는다.

장작 소리는 기존 직접 합성한 샘플을 재사용한다. 시각적 강조와 같은 시간표를 사용하되, 이번 3D 장면의 강조점을 실제 원-원 교차라고 잘못 설명하지 않는다.

## 실행 분담과 완료 조건

Terra6.1은 별도 `line-bulb` 페이지와 생성 코드를 담당하고, Astra는 실제 출력물을 검수한다. 총괄은 실제 UI 출력·파일 수집·FFmpeg 결합과 인계를 담당한다.

완료 조건: 실제 재생 가능한 소리 포함 5초 영상, 960×540 / 30fps / 150프레임, 읽히는 선과 입체감, 검증된 오디오 시간축. 검수 기록은 [line-bulb-critique.md](line-bulb-critique.md)에 둔다.

## 현재 상태

별도 5초 프로토타입 출력과 기술 검수 완료: `runs/line-bulb-v01/line-bulb-5s.mp4`. 독립 검수에서 960×540 / 30fps / 150프레임, 영상·음원 모두 정확히 5초, 48kHz 스테레오 AAC와 원본 WAV의 0샘플 지연을 확인했다. 실제 디코딩 프레임에서 가는 등고선과 가림은 확인했으나, 수평 단면 위주의 구성이라 입체감은 절제되어 있다. 청취에 따른 음색 평가는 하지 않았다. 이 결과물은 보존하며 현재 작업은 별도 30초 확장 영상으로 이어진다. 상세 근거는 [line-bulb-critique.md](line-bulb-critique.md)에 있다.
