# 현재 실행 상태

## 최신 확정 · 실제 Aphex Twin 원음으로 교체 예정

- 사용자가 비동기 질문에 명시적으로 답했다: ‘원음’은 **Aphex Twin 「#3」의 실제 녹음**이다. 이전에 자체 합성 바흐 마스터를 선택한 해석은 이 답으로 정정한다.
- 현재 continuum 영상에는 여전히 자체 합성 마스터와 하이햇이 들어 있다. 실제 녹음 교체가 끝났다고 보고하지 않는다.
- 다음 음원 작업은 실제 녹음을 원래 속도로 30초 구성하고 조용한 하이햇만 더하는 것이다. 기존 30초·720 영상은 보존한다.
- 현재 코드 변경과 이 결정 기록을 사용자 요청에 따라 GitHub에 푸시한다.

- 사용자 브라우저 피드백: 하이라이트 v01 음악이 빠르지 않게, 모래사장 디테일과 넓은 앵글의 희미한 세계 연속성, 더 섬세한 디밍·디퓨전, 더 많은 입자.
- 완료: `runs/dp-sts-gujora-continuum-v01/artwork.mp4`, 30초·720×720·24fps. 점 884,292개, 모래·외해·환경 안개를 별도 재질로 확장했다.
- 음악: v01에 사용한 압축 전 자체 합성 464초 마스터의 50–80초를 1배속으로 사용하고, 60BPM 하이햇만 추가했다. 실제 Aphex Twin 원음 삽입이나 참고곡 청감상 재현 검증으로 표현하지 않는다.
- 별도 완료: 기존 720 영상의 화면을 그대로 두고 음악만 교체한 `runs/dp-sts-gujora-audio-recut-v01/artwork.mp4`. FFmpeg 스트림 복사 후 영상 해시 일치를 확인했다.
- 검수: 모래가 어두웠던 첫 시안을 수정하고, Astra가 두 번째 실제 정지 표본을 수용했다. 최종 본편의 전체 디코딩과 입력 해시 검사가 통과했다. 사용자 미학적 승인은 미확정이다.
- [작품·변경 기록](../experiments/gujora-cover/continuum-film.md) · [비평과 실제 이미지](../experiments/gujora-cover/continuum-review.md).

## 이전 작업 · 30초 앰비언트 수정·720 출력

- 최신 사용자 판단: 30초 v01 음악 불수용. Aphex Twin #3처럼 느린 속도감과 질감이 필요하다. 영상의 464초 서사를 30초로 압축하는 것과 음악을 15배 이상 가속하는 것은 분리해야 한다.
- 새 목표: 영상 길이 30초, 720×720. 입자 442,146개·확장된 안개 공간·저음 반응·카메라 통과 후 형상 복귀는 유지한다.
- 새 음원: `runs/dp-sts-gujora-climax-v02/audio.wav`. 실제 Strudel BWV 846 음형을 기반으로 30초를 새로 합성했다. 느린 2.5초 음 진행, 6초 패드 어택, 8초 릴리스, 어두운 잔향을 사용한다. atempo 압축이나 Aphex Twin 원음 샘플을 사용하지 않는다. 직접 청취로 참고곡 유사성을 확인했다고 주장하지 않는다.
- 720 본편 완료: `runs/dp-sts-gujora-climax-v02/artwork.mp4`, 30초·720×720·24fps·720프레임. 전체 오디오/비디오 디코딩·입력 해시 검증 통과. 보관함에 새 시안을 등록했다. 이전 1080 v01은 기술 검사만 통과했고, 음악에 대한 사용자 불수용을 명시해 보존한다.
- 이전 464초 영상: `runs/dp-sts-gujora-spatial-v01/artwork.mp4`. 전체 기술 검사 통과 후 사용자 모아레 개선 요청을 받았다.
- 작품 보관함: `http://localhost:4200/gallery.html`. 기존과 새 결과를 자동 탐색하며 v01 음원 불수용과 v02 제작 상태를 구분한다.
- 코드베이스: https://github.com/bang1lee/ambient-lab (비공개). main 첫 푸시 완료. `runs/` 결과물과 로컬 환경·캐시는 포함하지 않는다.

## 이전 완료 작업 · 윤돌섬의 입자 장과 BWV 846 앰비언트

- 현재 확정 방향: 첨부 선화 구도를 보존한 3D 입자·연결선, 독립된 윤돌섬, 일곱 사람(남자 셋·남녀 커플·엄마와 아이), 원통 화롯대, 연기와 별의 연결, 해변 뒤쪽 유목.
- 음악: 바흐 BWV 846 첫 네 마디의 반복 음형을 실제 Strudel로 구성한 476개 이벤트. 새 180초·48kHz 스테레오 WAV와 4,320개 영상 제어 프레임 생성. Aphex Twin #3는 공식 재생 자료의 수치 음량 흐름과 앰비언트 방향을 참조했으며, 악기·편곡 동일 재현이나 직접 청취 검증이라고 주장하지 않는다.
- 검수: v01·v02 실제 시안은 기호 같은 인물, 읽히지 않는 수면·겹선 때문에 불수용. v03은 원본 선 픽셀을 3D 입자로 변환하고 이웃한 입자의 공통 움직임을 구현. Astra가 15·72·110·150초 실제 프레임을 확인해 정지 시안으로 수용했다.
- 공유: 수정 전 실제 이미지, 수정된 15·110초 이미지, 새 음악 30초, 음악과 연결한 12초 실제 영상을 사용자에게 공개했다.
- 출력 완료: `runs/dp-sts-gujora-particles-v01/artwork.mp4` 180초·1080×1080·24fps·4,320프레임. 최종 전체 디코딩·음원 수치·이미지와 코드 및 음원 출처 검사 통과. 15초 미리보기와 최종 MP4에서 추출한 9시점 검수 보드 생성. 최종 이미지의 독립 검토는 별도 기록한다.
- 기록: [본편과 검증](../experiments/gujora-cover/particle-film.md), [최신 디렉션](../experiments/gujora-cover/particle-direction.md), [시안별 독립 검수](../experiments/gujora-cover/particle-review.md).
