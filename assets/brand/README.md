# dp-sts cover

`dp-sts-cover-v01.png` is an AI-generated project cover, created on 2026-11-03 with the built-in image generation tool and inspected before publication in the repository README.

Direction: extreme macro photography of two adult forearms touching, one with deep brown skin and one with warm light skin. Gloss, fine hair, pores and goosebumps form a tactile landscape around the diagonal contact seam. No text or identifiable real person is depicted.

The project owner requested this cover and its upload to the private GitHub repository. It is a new branding asset, not a frame from an existing film or a replacement for the Gujora artwork.
